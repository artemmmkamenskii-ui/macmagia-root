# Скилл «SEO-аудит» для Claude Code

Готовый порядок SEO-аудита сайта: что проверять, в каком порядке, на что не
тратить время и где обычно прячутся дефекты, которых не показывает ни одна
панель. Собран по итогам реальных аудитов интернет-магазина и сети контентных
сайтов, дописывается после каждого разбора.

## Что это такое

«Скилл» в Claude Code — файл с инструкцией, который подключается по команде.
Написав `/seo-audit ваш-сайт.ru`, вы запускаете не один запрос, а весь описанный
здесь порядок работы: Claude сам ходит по панелям, считает выборки, сверяет
цифры и разбирает находки.

Нужен **Claude Code** (claude.com/claude-code). В обычном чате скилл не
подключить — там просто скопируйте содержимое `SKILL.md` в сообщение, порядок
проверок останется полезным, но всё придётся делать вручную.

## Установка

Положите папку `seo-audit` (с файлом `SKILL.md` внутри) в один из каталогов:

- `~/.claude/skills/seo-audit/SKILL.md` — скилл будет доступен во всех проектах;
- `<папка проекта>/.claude/skills/seo-audit/SKILL.md` — только в этом проекте.

Перезапустите Claude Code. Проверить, что подхватилось: команда `/` покажет
`seo-audit` в списке.

## Как пользоваться

```
/seo-audit example.ru
```

Дальше Claude спросит, к чему у него есть доступ. Чем больше дадите, тем
глубже разбор:

| Что | Зачем | Обязательно? |
|---|---|---|
| Яндекс.Вебмастер (OAuth-токен или вход в браузере) | индекс, запросы, диагностика, переобход | да, иначе половина шагов отпадает |
| Google Search Console (вход в браузере) | причины непопадания в индекс, позиции | да |
| Логи веб-сервера | реальный список рекламных меток, поведение роботов | нет, шаг пропускается |
| Доступ к коду сайта | чинить найденное, а не только описывать | нет |

Токен Вебмастера получается в [Яндекс OAuth](https://oauth.yandex.ru/) для
API Вебмастера; Search Console открывается обычным входом в браузере.

## Чего скилл НЕ делает

- не покупает ссылки и не занимается ничем серым;
- не заменяет платные сервисы вроде Ahrefs — внешние ссылки и позиции
  конкурентов он не видит, работает с вашими собственными данными;
- не гоняет обход по всей карте сайта: это боевой сервер, его берегут.

## Обратная связь

Скилл имеет смысл дописывать: каждая проверка, которую пришлось придумать по
ходу очередного аудита, добавляется в файл. Тогда следующий аудит начинается
не с нуля. Это прямо прописано последним шагом внутри.
