# ТЗ для агента в проекте `/cards` (лендинг колод)

> Передать агенту, работающему в Next.js-приложении страницы `https://macmagia.ru/cards`.
> Цель: закрыть коммерческий запрос «метафорические карты / МАК купить / скачать» — самый ценный интент (покупатели).
> Контекст: [content-plan.md](content-plan.md) §0 (позиционирование).

---

## Контекст и зачем

`/cards` — страница продажи электронных колод МАК. Она существует и индексируема, но **не оптимизирована под коммерческие запросы**, по которым её ищут покупатели. Внутренняя перелинковка и sitemap уже настроены на стороне лендинга — **трогать не нужно**.

Главная проблема: meta-теги не под запрос, а в `description` сейчас вообще техническая заглушка для разработчика («Мини-лендинг для продажи…»).

### Целевые запросы (Wordstat, частота/мес)
- `метафорические карты купить` — 998 (главный)
- `мак карты купить` — 583
- `метафорические ассоциативные карты купить` — 84
- `метафорические карты где купить` — 44
- `метафорические карты цена` — 32
- `купить метафорические карты онлайн` — 27
- `метафорические карты для психолога купить` — 26
- `колоды мак карт купить` — 25
- `интернет магазин метафорических карт`, `магазин мак карт` — хвосты
- **`метафорические карты скачать` (808) + `мак карта скачать` (616)** — ~1,4K/мес «скачать»-интент. Электронная колода по сути и есть «скачать» — это надо явно отразить (после оплаты колода доступна сразу, работает в браузере/телефоне). Перехватываем тех, кто ищет «скачать бесплатно», и предлагаем легальную цифровую колоду.

Интент — транзакционный: человек готов купить/скачать. Страница должна явно отвечать «здесь можно купить и сразу получить колоду МАК».

## Жёсткое правило позиционирования (content-plan §0)
Психологический инструмент, не эзотерика. Запрещено: «гадание», «предсказание», «магические карты». Термин — «метафорические ассоциативные карты (МАК)».

---

## Задача 1 — Мета-теги (обязательно, критично)

Сейчас:
- `<title>`: `Электронные колоды` — нет ни «купить», ни «метафорические карты», ни «МАК»
- `<meta description>`: `Мини-лендинг для продажи электронных колод…` — это **внутренняя заметка разработчика**, её нельзя показывать в выдаче

Заменить на:
- **title:** `Купить метафорические карты (МАК): электронные колоды — МакМагия`
- **description:** `Купить метафорические ассоциативные карты (МАК): авторские электронные колоды с мгновенной отправкой на email и работой прямо в телефоне. Колоды для психологов и для себя, оплата онлайн.`

Проверить: `canonical` = `https://macmagia.ru/cards`, полный OG (og:title/description/url/image), нет `noindex`.

## Задача 2 — H1 и заголовки

Сейчас H1 = «Твоя личная колода МАК всегда в телефоне» (выгода, без ключа «купить/метафорические карты»).
- Сделать **H1** с вхождением ключа, сохранив маркетинг. Вариант: `Купить метафорические карты (МАК): электронные колоды` либо оставить хук, но добавить keyworded H2 высоко на странице.
- Среди H2 иметь формулировки с «купить колоду МАК», «скачать метафорические карты», «метафорические карты для психолога», «цена / что входит».

## Задача 3 — Вплести ключи и закрыть транзакционные вопросы

В видимом тексте органично использовать (без переспама):
- `купить метафорические карты`, `мак карты купить`, `колоды МАК купить`
- `скачать метафорические карты` / колода доступна для скачивания после оплаты
- `метафорические карты для психолога` (отдельный сегмент покупателей)
- `цена`, `что входит в колоду`, `как получить после оплаты`

Добавить короткий блок/FAQ под транзакционные вопросы (если их нет):
- «Сколько стоит колода и что входит» (цена — частый запрос)
- «Как получить и скачать колоду после оплаты» (мгновенная отправка, работа в телефоне)
- «Электронная или печатная — в чём разница» (если есть печатные/Wildberries — дать ссылку)
- «Подходит ли для работы с клиентами» (сегмент психологов)

## Задача 4 — Структурированные данные (Product / Offer schema)

Добавить JSON-LD `schema.org/Product` для колод (или `ItemList` из нескольких Product), с `offers` (цена, валюта RUB, `availability`). Это даёт шанс на расширенный сниппет с ценой в выдаче — сильное преимущество для коммерческого запроса.

## Проверка результата (агент показывает вывод)

1. `curl -sL https://macmagia.ru/cards | grep -oE '<title>[^<]*</title>'` → содержит «купить» и «метафорические карты».
2. В HTML: description БЕЗ слова «мини-лендинг», с ключами; canonical; OG; нет noindex.
3. H1 содержит ключ; в тексте есть «купить метафорические карты», «мак карты купить», «скачать», «для психолога».
4. Присутствует JSON-LD `"@type":"Product"` (или Offer) с ценой.
5. После деплоя — сообщить, чтобы владелец отправил `/cards` на переобход в Google/Яндекс.

- Внутренние ссылки из блога (статья «Как выбрать колоду МАК» ведёт на `/cards`).
- Отправка на индексацию — сделает владелец после деплоя.
