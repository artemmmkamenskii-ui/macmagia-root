# ТЗ: стилистическая правка статей женской воронки /artterapy (G1 + дедуп)

> Объективные/safety/фактчек правки УЖЕ внесены. Эта задача — ТОЛЬКО стилистика: G1 (антитезы),
> дедуп соседних статей, разнообразие CTA, блок-различений и упражнения «коллаж».
> Эталон регистра — `docs/seo/articles/kak-prinyat-i-polyubit-sebya.md` (уже отредактирована, НЕ трогать).

## КРИТИЧЕСКИЕ ПРАВИЛА (нарушение = откат)
1. **Править ТОЛЬКО `docs/seo/articles/<slug>.md`.** HTML (`blog/*.html`) генерируется сборкой — не трогать.
2. **Эзо-фильтр:** НЕЛЬЗЯ слова `магическ*`, `волшебн*`, `гадание/гадать`, `таро`, `руны`, `гороскоп`, `астролог*`, `эзотерик*`, `предсказани*/предсказать`, `прорицани*`, `карма*`, `чакр*`, `биополе`, `карта дня`, `расклад на будущее` — даже в отрицании (сборка падает). Синоним для «гадания» — «угадывание / получить готовый ответ извне».
3. **НЕ удалять и НЕ менять по смыслу:** телефоны `8-800-2000-122`, блоки «Когда нужен специалист»/критерии депрессии/признаки РПП, фактчек «~70%», CTA-ссылки `::: cta /artterapy`, frontmatter, перекрёстные ссылки `/blog/*.html`, структуру H2/FAQ.
4. **В статье про заедание (zaedanie-emocij): ЗАПРЕЩЕНО** добавлять любые числа по еде/калориям/весу/диетам.
5. Объём не сокращать радикально (статьи 1400–2000 слов — норма). Голос — от лица Екатерины, тёплый, без морализаторства.

## ЧТО ДЕЛАТЬ

**G1 — антитезы.** Найти конструкции «не X, а Y» / «дело не в…, а в…» / «это не …, это …». Оставить максимум 1–2 на статью (обычно — ту, что в плашке `::: pullquote`). Остальные переписать в прямые утверждения. Пример из эталона: было «Это не „борьба с собой“, а возвращение себе власти» → стало «Так вы возвращаете себе власть».

**Дедуп соседних статей** (сверять между собой, не править изолированно):
- апатия ↔ ресурс: «микрошаги», «один мазок», «низкий порог», различение с депрессией/выгоранием — развести формулировки.
- кризис ↔ поиск себя ↔ опустевшее гнездо: «заглушённые хочу», «жить для других», коллаж — развести.
- тело ↔ заедание: РПП-оговорки — развести формулировки.
- страх проявляться ↔ творческий блок: «страх оценки / внутренний критик» — развести.
- прожить эмоции ↔ гнев: «обида = подавленная злость», «уходит в тело/психосоматику/вспышки» — развести (в гневе оставить, в эмоциях обобщить иначе).

**Упражнение «Коллаж без ограничений / без цензора»** встречается почти дословно в kak-najti-sebya, krizis-srednego-vozrasta, opustevshee-gnezdo (+ был в ст.1). Переформулировать каждое по-своему (разные инструкции, разный фокус).

**CTA-хвост.** Если в `::: cta` есть шаблонные «в безопасном темпе и с сопровождением» — переписать под тему своими словами (в части статей уже сделано — не дублировать соседние).

**Блок-различение «X vs депрессия/выгорание»** (в krizis, opustevshee, kak-vosstanovit-resurs) — переписать формулировки, оставив суть и критерии. Эталон-формулировку оставить в `apatiya.md` (НЕ трогать её различение).

**«парадокс/парадоксально»** — снизить частоту по циклу (если встречается — заменить).

**Зачин «Я психолог, и это одна из самых частых тем»** — если есть, в части статей заменить на конкретику (наблюдение/мини-сцена/факт), чтобы не повторялось.

## ПОСЛЕ ПРАВКИ
Не собирать билд (это сделает владелец). Просто сохранить .md. Сообщить список изменённых файлов и что именно сделано.
