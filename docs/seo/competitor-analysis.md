## 2. Топ-7 эталонов качества

Что копируем у каждого, что улучшаем:

### 1. b17.ru (8,8M/мес) — главный эталон рынка
- **Сила:** объединил агрегатор психологов + массив тестов + блог 50K+ авторов. Топ-ключи: «тест на расстройство личности» (43K), «MBTI-тест» (20K), «тест на нарциссизм» (12K).
- **Формат:** статьи 800–2500 слов, H1+5–10 H2, под статьёй карточка автора с CTA «записаться».
- **Что копируем:** двойная аудитория (психолог=автор, клиент=читатель), карточка автора, мега-каталог тестов.
- **Что улучшаем:** их качество отдельных статей низкое (фабрика). Мы выиграем глубиной по нишам МАК / арт-терапия / AI.

### 2. www.psychologies.ru (2,7M/мес) — глянцевый эталон
- **Сила:** редакторский глянец, ВПР-тесты, «горячие» темы.
- **Формат:** оглавление + 1500–3000 слов, 5–8 H2, экспертные цитаты, иллюстрации в каждом блоке, related в конце.
- **Что копируем:** структуру лонгрида, оглавление-якоря, related-блок.

### 3. yasno.live (753K/мес) — топ-сервис подбора + тесты
- **Сила:** органический трафик идёт не от страниц подбора, а от психо-тестов (44K кликов на «тест на тяжёлый характер», 14K на «тест на ревность»).
- **Формат:** редакторские разборы 1500–2500 слов + отдельные лендинги для каждого теста с пошаговыми вопросами и CTA на консультацию.
- **Что копируем:** **психо-тесты как главный трафик-драйвер**. Для нас — мост МАК → тест («Тест: какая метафорическая карта про твоё состояние»).

### 4. defectologiya.pro (369K/мес) — нишевый лидер
- **Сила:** глубокая узкая ниша (дефектология, СДВГ, аутизм) + скачиваемые материалы.
- **Формат:** длинные статьи 2000+ слов, диагнозы/методики, таблицы и списки, PDF/карточки.
- **Что копируем:** пример того, как узкая ниша даёт большой трафик. Для нас — глубина по МАК.

### 5. psychologos.ru (280K/мес) — энциклопедический формат
- **Сила:** портал Николая Козлова, словарь-справочник по психо-терминам с богатой перелинковкой.
- **Топ-ключи:** «целостность это», «конструктивный подход», «структура личности по Леонтьеву».
- **Формат:** короткие словарные статьи 300–800 слов + большие 1500–3000.
- **Что копируем:** **формат глоссария** для МАК-терминологии (метафорический сюжет, ассоциативный ряд, проекция, символ).

### 6. talentsy.ru (397K/мес) — онлайн-универ психо-курсов
- **Сила:** SEO для курсов + большой блог-хаб лидогенерации, двойная аудитория.
- **Формат:** статьи 1500–3000 слов, оглавление, экспертные цитаты, врезки с CTA «получить курс», видео-вставки.
- **Что копируем:** структуру блог-статьи под лидогенерацию курсов `/ai`, `/artterapy`, `/mac`.

### 7. psyh.info (61,3K/мес) — массовая поп-психо
- **Сила:** объём (39K страниц), широкая семантическая ёлка.
- **Формат:** статьи 800–1500 слов, классический WP-блог.
- **Что копируем:** ширину тематик из кластера «эмоции/состояния» (для верха воронки).

## 3. Темы-обязательные (must-have семантика)

### Кластер A — психо-тесты (главный трафик-драйвер сегмента)
Тест на: MBTI / тип личности, расстройство личности (нарциссизм, пограничное, тёмная триада), стиль привязанности, психотипы/архетипы, отношения/совместимость/ревность, эмоциональный интеллект, тревогу/депрессию (Бек, GAD-7), выгорание, эмоции по картинкам.

**Для macmagia:** прямой мост — «Тест → результат-карта МАК → CTA на колоду».

### Кластер B — эмоции и состояния (массовый верх воронки)
Тревога, депрессия, выгорание, стресс, панические атаки, гнев/агрессия, стыд/вина, прокрастинация, одиночество.

### Кластер C — отношения
Психология отношений, любовь/расставание/развод, созависимость, токсичные отношения, привязанность, конфликты, манипуляции.

### Кластер D — самопознание и личностный рост
Самооценка, личные границы, эмоциональный интеллект, архетипы Юнга, психотравма, осознанность.

### Кластер E — родительство и семья
Воспитание по возрастам, психология подростка, детская тревога/страхи, СДВГ/аутизм, отношения родители-дети.

### Кластер F — психо-проф (аудитория «психологи»)
КПТ/гештальт/психоанализ/ACT/EMDR, психодиагностика, документация и МКБ, супервизия, работа с клиентом, психология как профессия.

## 4. Темы-возможности (где конкуренты слабы — наш приоритет)

1. **МАК как профессиональный инструмент психолога** — у b17 разрозненно, цельного hub-портала нет.
2. **МАК для самостоятельной работы клиента дома** (без эзо-окраски) — массово отсутствует.
3. **Арт-терапия как метод доказательной психологии** — у defectologiya только детская в коррекционке, у b17 — частные посты. Цельной hub-страницы нет.
4. **AI/нейросети в работе психолога** — **нулевое покрытие у всех 35 конкурентов.** Самый высокий ROI-кластер.
5. **Цифровые колоды МАК** (мобильные/веб-приложения) — никакого конкурента.
6. **Этика работы психолога с AI / приватность данных** — YMYL-тема, отсутствует.
7. **Профессиональная документация психолога** — только у psyjournals.ru академически. Популярного контента нет.
8. **Микро-курсы (1–2 часа)** — все конкуренты делают только большие курсы (40+ ч).
9. **Глоссарии и справочники** — отлично делает только psychologos. Для МАК-терминологии — пустое поле.

## 5. МАК — ниша почти не занята

**Прямых ТОП-ключей по «мак», «метафорические карты», «ассоциативные карты» в pr-cy не видно ни у одного из 35.** Эти запросы либо не в ТОП-50 у конкурентов, либо низкочастотные (требует валидации Wordstat).

**Кто хоть как-то касается МАК:**
- b17.ru — авторские посты психологов, использующих МАК. Тон психологический, без эзо.
- psychologos.ru — нет в ТОП-ключах.
- psy-practice.com, psy.su — отдельные посты.
- Остальные 30 — не касаются.

**Тон конкурентов в наших темах:** где МАК упоминается у психологов — **психологический инструмент** без эзо-окраски. Эзо-кластер (таро/гадание) в выборке отсутствует — фильтр сработал чисто.

**Вывод:** ниша МАК **слабо занята SEO-сильными игроками.** Окно для топа русскоязычной выдачи по «метафорические карты» / «МАК в работе психолога» — открытое, при условии:
- hub `/mac/` или `/cards/` с E-E-A-T-сигналами;
- 30–50 статей кластера «МАК + ...»;
- жёсткое позиционирование «инструмент психолога», не «магия».

## 6. Арт-терапия — частично занята

**Прямых ТОП-ключей нет** (низкочастотные). Кто касается:
- defectologiya.pro — детская арт-терапия в коррекционке.
- mgppu.ru, mip.institute, inpsycho.ru, ippss.ru, psychodemia.ru, imaton.ru — программы повышения квалификации.
- talentsy.ru — курсы.
- b17.ru — авторские посты.

**Чего нет:** отдельного контент-портала про арт-терапию для взрослых, со структурой «направление → техника → методика → сессия с клиентом». Вторая ниша-возможность для macmagia.

## 7. AI в психологии — белое пятно

**Покрытие у всех 35 конкурентов — нулевое.** В ТОП-ключах AI-темы не встречаются ни у кого.

**Окно для macmagia + provizorai:**
- Запросы: «AI психолог», «нейросеть для психолога», «ChatGPT для работы психолога», «искусственный интеллект в психотерапии», «AI документация психолога», «AI этика психологическая практика».
- Кросс-линкинг с provizorai (см. donors-shortlist §5).
- Тема YMYL — нужен автор-психолог, ссылки на исследования (Llewellyn Cordeiro 2024, APA-guidelines на AI), без обещаний «AI заменит психолога».

## 8. Стандарт формата (из топ-конкурентов)

**Длина:**
- Поп-психо лонгрид: 1500–3000 слов.
- Глоссарные/энциклопедические: 400–800 слов с густой перелинковкой.
- Профессиональный лонгрид: 2000–4000 слов.
- Тесты: отдельный лендинг + статья «что такое X» 1000–2000 слов.

**Структура (стандарт топа):**
1. H1 + краткий лид 2–3 предложения.
2. Оглавление-якоря (psychologies, yasno, talentsy).
3. 5–10 блоков H2; внутри H2 — 2–4 H3 при необходимости.
4. Экспертная карточка автора (стандарт b17, psychologies).
5. Иллюстрация в шапке + 2–4 встроенных.
6. 1–2 экспертные цитаты или ссылки на исследования.
7. FAQ-блок 5–8 вопросов в конце (talentsy, psy-practice, yasno).
8. Related-блок «Читайте также» 3–5 ссылок.
9. CTA в конце: для нас — на курс/колоду.
10. Турбо-страницы Яндекса — включить с самого старта.

**Частота публикаций:** реалистично для старта — **2 статьи/неделю** первые 6 месяцев, далее **3–4/неделю**.
