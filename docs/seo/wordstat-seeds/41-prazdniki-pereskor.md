# 41. Праздники — пересбор тремя кустами

Сбор 39 провалился: из 2 000 фраз сида «итоги года» личных оказалось 25
(1,25%), остальное — фича Яндекс.Музыки «Итоги года», выборы, учебный год и
корпоративная отчётность. Голова с чужим владельцем, случай правила 6.

Три ошибки: сиды были глагольными фразами из двух-трёх слов; «итоги года» —
омоним с гигантским чужим владельцем; ни одного сида с самооценкой внутри.

Здесь заходим иначе — человек описывает свою ситуацию, а не называет дату.
Голыми «новый год», «день рождения», «8 марта» не берём: даже с отсевом
открыток и рецептов доля нашего интента там будет процента три.

Гнать в первой половине октября: замерить до всплеска и успеть в индекс к
декабрю.

```
не с кем встретить новый год
некуда пойти на новый год
никто не зовет на новый год
одна в новогоднюю ночь
первый новый год без мамы
первый новый год после развода
новый год без семьи
не радуют праздники
устала от праздников

вопросы для подведения итогов года

```
