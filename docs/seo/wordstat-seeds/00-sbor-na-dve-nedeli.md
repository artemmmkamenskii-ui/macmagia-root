# Сбор под две недели публикации (280 статей)

Составлено 22 сентября 2026, когда очередь кончилась. Все прежние сборы
выбраны до дна.

## Сколько надо собрать

По опыту девяти волн: **один сид даёт 100–600 фраз, из них 1–5 годных тем.**
Выход зависит от того, закрыто ли направление в блоге:

| направление | выход |
|---|---|
| свежее, статей нет | 12–37% |
| частично закрытое | 5–12% |
| выбранное (цели, психология) | 0–3% |

Чтобы получить 280 тем, нужно **50–60 сидов по свежим направлениям**.
Собирать пакетами по 8–10 фраз, файлы класть в папку `ключи`.

Важно: сид — фразой целиком, не одним словом. Однословные («цель»,
«стесняться», «ложь», «манипуляция») приносят госплан, порно, романы и
учебники для медсестёр — проверено.

## Как отдавать

Каждый блок — отдельным пакетом, по мере сбора. Не обязательно всё сразу:
разбор одного блока занимает около часа, статьи пишутся партиями по 5–6.

Приоритет по срочности: **1 (сезон) → 2 → 8 → 3**, остальные в любом порядке.
