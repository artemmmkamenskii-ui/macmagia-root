# 13. Братья и сёстры

Ноль статей: слова «сестра» и «сиблинг» нет ни в одном из 620 заголовков.
При этом детская психология — третья по величине категория блога (68
статей), и она вся про отношения с родителями, ни одной про отношения
между детьми. Направление закрывает обе стороны: мать двоих детей читает
про ревность старшего, взрослая женщина — про счёты с сестрой.

Подтемы: ревность старшего · любимчик · соперничество · взрослые
сиблинги · дележ заботы о родителях · наследство и обиды
