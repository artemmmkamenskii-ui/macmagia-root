# 42. Праздники — третья попытка, голые слова

Сбор 39 (фразы из двух-трёх слов) дал 2 201 фразу, из них личных 25.
Сбор 41 (формулировки с самооценкой, по рекомендации редактора) дал
**41 фразу со всех двадцати сидов** — то есть провалился ещё сильнее.

Вывод, который стоит запомнить: самооценочная формулировка сама по себе
ничего не гарантирует. «Ненавижу праздники» — 5 фраз, «не радуют
праздники» — 3, «тяжело на семейных праздниках» — 0. Объём даёт только
короткий сид, и «ничего не добилась» сработало не потому, что оно
самооценочное, а потому что его реально набирают.

Остаётся последний вариант: голые названия с тяжёлым отсевом на
редакторе. Редактор предупреждал, что доля нашего интента там будет
процента три, — но три процента от миллиона больше, чем сто процентов
от сорока одной фразы. Проверяем.

```
новый год
праздники
день рождения
корпоратив
новогодняя ночь
отмечать
застолье
юбилей
праздничный стол
выходные дни
```
