# 37. Близость и влечение — широкими словами

Замена сидам из 11-blizost-i-zhelanie: там были длинные фразы вроде «чувство
вины за отказ близости» — такие дают ноль. Берём короткие однозначные слова.

Риск направления — порно: сид «секс» отдаёт его целиком, поэтому его здесь нет.
«Влечение» и «либидо» однозначны и порно почти не тянут.

```
влечение
либидо
муж не хочет
фригидность
интимная жизнь
страх близости
объятия
отказ в близости
холодность в отношениях
пропало желание
```
