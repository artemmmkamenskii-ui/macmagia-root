# 14. Переезд и новое место

Ноль статей: ни «переезд», ни «новый город», ни «эмиграция» не встречаются
в заголовках. Направление смыкается с уже сильной дружбой (потеря круга —
одна из главных причин, по которой у взрослой женщины исчезают друзья) и с
одиночеством, где у нас 347 упоминаний, но ни одной статьи про его
конкретную причину.

Пишем про переживание, не про логистику: чемоданы, документы и аренду не
трогаем.

Подтемы: одиночество на новом месте · тоска по прежней жизни · переезд
ради мужа · дети в новой школе · возвращение · «нигде не дома»

```

```
