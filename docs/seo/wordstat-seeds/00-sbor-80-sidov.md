# Сбор на 280 статей: 80 сидов

Составлено 22 сентября 2026. Арифметика по девяти волнам: **один сид даёт
3–4 статьи**. Значит на две недели публикации по 20 в день нужно около
80 сидов.

## Главное правило, выведенное из волны 10

Сид — это **фраза, которую человек печатает в поиск в трудный момент**.
Не абстракция и не выдумка составителя.

| сид | фраз собрано | статей |
|---|---|---|
| подросток не хочет учиться | 32 | **10** |
| муж не помог | 237 | **5** |
| мама ухаживает за мамой | 163 | **4** |
| подростки (широкое слово) | 2000 | 1 |
| кризис 3 лет | 2733 | **0** — там кризис 1929 года |
| дети просят собаку (выдумка) | 24 | 1 |

Тридцать две фразы дали десять статей, две с лишним тысячи — ноль. Объём
сбора не важен, важна живость ситуации: у настоящей боли длинный хвост
формулировок, и из него выходят статьи.

Собирать каждую строку отдельно, листать вглубь. Файлы класть в папку
`ключи` внутри проекта.

## Порядок

Собирать пакетами по 10 сидов, отдавать по мере готовности. Один пакет —
это примерно 30–40 статей, то есть два дня публикации.

Приоритет: **Г (ноль статей) → Б → А → З**, остальные в любом порядке.
