# 50. Переезд и новое место

Последнее нетронутое направление из плана (14). В корпусе про это нет
ничего, хотя переезд — частая причина исчезнувшего круга общения.

Сиды короткие. Ожидаемый мусор: «переезд» — грузчики и перевозки,
«эмиграция» — политика и визы, «адаптация» — биология и детский сад,
«ностальгия» — музыка и названия кафе.

```
ностальгия
эмиграция
релокация
переезд в другой город
новый город
тоска по родине
скучаю по дому
адаптация в новой стране
вернуться домой
чужой город
```
