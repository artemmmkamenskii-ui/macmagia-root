# 47. Потеря ребёнка

Самая крупная незакрытая дыра корпуса, найдена в сборе по сиблингам:
4 746 показов. В блоге есть «как пережить смерть мамы», «отца», «питомца»,
«умерла подруга» — про ребёнка нет ничего.

Из сбора 45 тему тащить было нельзя: там фразы стояли вплотную к выплатам
и СВО, интент смешанный. Здесь заходим прицельно.

Тема требует рамки безопасности по правилу №6 HANDOFF: телефон доверия,
отсылка к специалисту, никакой бодрости и никаких сроков «когда отпустит».

Ожидаемый мусор, который надо отсечь на редакторе: выплаты и пособия,
СВО, уголовные дела, новости, сериалы, сонники.

