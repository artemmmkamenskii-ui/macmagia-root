# 36. «Поздно» и «не успела» — состояния вместо возраста

Выведено из волны 12: слово «старение» как сид даёт старение масел, металла
и коррозии; «возраст женщины» — порно и таблицы норм; «менопауза» — аптеку.
Психологию возраста надо брать через состояния, а не через само слово.

```
поздно начинать
уже поздно менять
не успела
жизнь проходит мимо
завидую молодым
все успели а я нет
время уходит
ничего не добилась
не так представляла жизнь
упустила время
```
