## Главный принцип фильтрации
`/artterapy` — для взрослых «для себя», НЕ для специалистов/детей. Поэтому:
- ✅ берём: эмоциональная самопомощь взрослых
- ❌ НЕ берём на `/artterapy`: детский/специалистский/методический кластер (нужен отдельный проф-продукт)
- ❌ выкидываем гео-варианты (алматы/спб/москва — оффлайн-интент) и «внутренняя опора» (брендовый запрос книги Анны Бабич)

## Кластер PROB-D — чистые проблемы (модель коучинга, ПРИОРИТЕТ 2)
Без слова «арт-терапия». Ловим через креативный угол → `/artterapy`. Конкуренция выше — выигрываем углом + E-E-A-T.
