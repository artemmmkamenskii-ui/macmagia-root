## Сильный сигнал интента
Частые модификаторы в подсказках: `слушать`, `слушать онлайн`, `без слов`, `текст`, `женский голос`.
→ Люди хотят **слушать прямо сейчас**. Статья даёт это (встроенное видео) + объясняет, как и зачем — это и удержание, и ранжирование.
Дропнуть брендовые/чужие: `барановский`, `вальяк`, `дзен`, `рутуб`, `кундалини`.

## Кластеры → статьи (по 4 темам видео)

### 1. Сон / расслабление
Ключи: медитация для сна, для сна и успокоения нервов (+ слушать онлайн / без слов / текст), для расслабления, для глубокого сна и восстановления сил.
→ статья: **«Медитация для сна и успокоения нервов (слушать)»** + видео.

### 2. Тревога / стресс / успокоение
Ключи: медитация для успокоения нервной системы и психики, для успокоения мыслей/ума/души, от тревоги, при тревожности.
→ статья: **«Медитация для успокоения нервной системы: как снять тревогу»** + видео.

### 3. Самоценность / принятие себя / женские
Ключи: медитация на принятие себя, на высокую самооценку, на благодарность и принятие себя, для женщин (любовь к себе / утром / слушать).
→ статья: **«Медитация на принятие себя и любовь к себе»** + видео. (Связка с арт-терапией для самооценки.)

### 4. Ресурс / восстановление / утро
Ключи: медитация для восстановления сил и энергии, для быстрого восстановления, утренняя, исцеление внутреннего ребёнка.
→ статья: **«Медитация для восстановления сил и энергии»** + видео. (Связка со статьёй `vygoranie` → `/artterapy`.)

## Шаблон статьи (чтобы не быть тонкой и ранжироваться)
1. H1 с ключом «медитация для X».
2. Короткий текст: что это за медитация, кому подходит, как слушать (наушники, время, поза) — 300–600 слов.
3. **Встроенное видео** (YouTube iframe + ссылка на VK) — как в статье `znachenie-i-rasshifrovka-mak`.
4. Блок «как часто / эффект / противопоказания» (если острое состояние — к специалисту).
5. Мягкий CTA на `/artterapy` («если хочется системной работы с состоянием…»).
6. FAQ под listen-интент: «можно ли слушать перед сном», «нужны ли наушники», «сколько раз».

## Что нужно для написания
- **URL роликов VK + YouTube по каждой из 4 тем** (чтобы встроить правильное видео в правильную статью).
- Прогон Wordstat по головам: «медитация для сна», «медитация для успокоения нервной системы», «медитация на принятие себя», «медитация для восстановления сил».

## Каннибализация / связки

- Не конфликтуют с арт-статьями: разный интент (слушать vs рисовать), но обе ведут на `/artterapy`.
