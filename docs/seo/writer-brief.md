## 0. О проекте — read me first

**macmagia.ru** — бренд-хаб: курсы для психологов + метафорические ассоциативные карты (МАК) + AI-инструменты + арт-терапия. Аудитория **двойная**:

- **«Психологи»** (профи) — приходят за курсами, методиками, инструментами. Ведут платную выручку.
- **«Клиенты»** (саморазвитие) — приходят за разбором эмоций, тестами, картами для себя. Покупают цифровые/печатные колоды.

**Авторы — два голоса** (см. [agent-task.md §1](agent-task.md)):

| Тип статьи | Автор |
|---|---|
| МАК для психолога, методики, кейсы, AI для психолога | **Екатерина Каменская** (от 1-го лица, «старшая коллега за чашкой чая») |
| Что такое МАК / арт-терапия — pillar-статьи | Екатерина |
| Поп-психология (тревога, депрессия, СДВГ — что это), обзоры тестов, глоссарий, классические концепты | **«Редакция МакМагии»** (журналистский тон, с пометкой «материал проверен Е. Каменской, психологом») |

Решение по голосу — в [agent-task.md §1 «Когда какой голос — таблица решений»](agent-task.md).

**Связанный проект** — `provizorai.ru` (AI-софт для психологов). Кросс-линкование с ним органично, но строго по контексту (см. donors-shortlist §5).

## 1. КРАСНАЯ ЛИНИЯ — эзо-фильтр (нарушение = отказ от публикации)

В бренде есть слово «Магия». В выдаче МАК-карты соседствуют с таро/гадания/руны. Это **главный риск** проекта: скатиться в эзотерический кластер Яндекса → потеря YMYL-trust → потеря всей выдачи.

### Запрещено в любой статье

- ❌ Слова: «магия», «гадание», «гадать», «таро», «руны», «эзотерика», «предсказание», «судьба», «карма», «энергия» (в эзо-смысле), «астрология», «нумерология», «хиромантия», «ангелы», «высшие силы», «послание Вселенной», «знаки», «синхроничность» (в Юнгианском смысле — разрешено, но осторожно).
- ❌ Формулировки: «карты подскажут судьбу», «откроет тайны», «прочитает будущее», «расскажет правду о…», «карты знают», «магически», «волшебно».
- ❌ Сравнение МАК с таро в положительном ключе («МАК — это современное таро»). Сравнение в отстраивающем ключе **обязательно** (см. статью #9 в [content-plan §2](content-plan.md#L68)).
- ❌ Слова-маркеры эзо-копирайтинга: «энергетика человека», «чакры», «биополе», «вибрации», «привлечение денег», «привлечение любви», «исполнение желаний», «портал», «магический ритуал».
- ❌ Заголовки-приманки эзо-формата: «Что говорят о тебе карты?», «Карта дня», «Откроем твою судьбу».

### Что говорим вместо

- ✅ «Метафорические ассоциативные карты (МАК)» — полное название при первом упоминании в статье. Далее — «МАК», «карта», «изображение», «метафорическая карта», «колода».
- ✅ «Помогает осознать», «запускает ассоциации», «активирует внутренний диалог», «инструмент рефлексии», «проективный метод», «диагностический инструмент», «помогает сформулировать запрос».
- ✅ «Психологический инструмент», «арт-терапевтический приём», «техника работы с клиентом», «упражнение для самопознания».
- ✅ В контексте Юнга — допустимы термины «архетип», «символ», «коллективное бессознательное», «индивидуация», «синхроничность» — только с академической ссылкой (Юнг, Хиллман и т.п.), не в массовом эзо-смысле.

### Проверка перед публикацией (чек-лист эзо-фильтра)

Открой готовую статью, нажми Ctrl+F, ищи каждое слово из запрещённого списка. Найдено хоть одно — статья на доработку.

## 2. Структура статьи (обязательная)

Эталон взят с топ-конкурентов: www.psychologies.ru, yasno.live, talentsy.ru, psychologos.ru. См. [competitor-analysis.md §8](competitor-analysis.md).

### 2.1. Hero-блок

1. **H1** — заголовок (см. §6 правила заголовков).
2. **Лид** — 2–3 предложения, что узнает читатель и почему ему это нужно. Без воды.
3. **Карточка автора** — имя, регалии, фото (всегда Екатерина, шаблон один и тот же).

### 2.2. Оглавление-якоря

После лида — оглавление со ссылками-якорями на H2. Обязательно для статей длиннее 1500 слов.

### 2.3. Тело

- **H2** — 5–10 блоков на статью. Каждый H2 — один логически законченный смысловой блок 200–400 слов.
- **H3** — внутри H2 при необходимости (1–3 H3 в одном H2). Не использовать H4 и глубже.
- **Абзацы** — 3–5 предложений максимум. Длинные сплошные простыни запрещены.
- **Списки** — bullets/numbered, не злоупотреблять (не превращать в «N способов»).
- **Цитаты экспертов** — 1–2 на статью (можно от автора Екатерины, можно ссылку на известного психолога — Юнг, Винникотт, Боулби, Линехан, Бек).
- **Ссылки на исследования** — 1–2 на статью для YMYL-тем (PubMed, APA, Cyberleninka).
- **Иллюстрации** — 3–5 на статью: hero-картинка + 2–4 в теле. Для МАК-статей — реальные карты из наших колод (придают визуальную идентичность).

### 2.4. Заключительный блок

- **FAQ** — 5–8 коротких пар вопрос-ответ, каждый ответ 2–4 предложения. Обязательно для статей-вопросов и лонгридов.
- **Заключение** — 2–4 предложения, краткое резюме (не итоговый список, а связный текст).
- **CTA** — одна кнопка/ссылка на коммерческую цель: `/cards` (купить колоду), `/mac`, `/ai`, `/artterapy` (записаться на курс). Один CTA, не три.
- **Related** — блок «Читайте также» — 3–5 ссылок на другие статьи блога по той же теме.

### 2.5. Технические элементы (заполняет агент)

- Title (60–65 знаков, см. §5).
- Description (140–155 знаков, см. §5).
- URL-slug (см. §5).
- OG (Open Graph) — title, description, image.
- JSON-LD Article — author Екатерина, publisher МакМагия, datePublished, dateModified.

## 3. Длина статьи

| Тип статьи | Длина |
|---|---|
| Pillar (опорная) — кластер A или B | **2500–4000 слов** |
| Стандартная статья блога | **1500–2500 слов** |
| Глоссарная статья (термин) | **400–800 слов** с плотной перелинковкой |
| Лендинг психо-теста | отдельная страница, вокруг неё статья «что такое X» — 1000–2000 слов |

Короче 1500 слов — только для глоссария. Длиннее 4000 — разбивать на 2 материала и связывать перелинковкой.

Подсчёт без учёта оглавления, FAQ и related-блока.

## 4. Тон голоса (voice & tone)

**Базовый принцип:** говорим как **психолог-эксперт**, который объясняет сложные вещи **просто, тепло и без эзо-маркеров**.

### Что да

- Уважение к читателю: «вы», не «ты» (если не подростковая аудитория).
- Простой русский язык, минимум жаргона. Если используем термин — сразу объясняем (как Wikipedia).
- Конкретные примеры: «Например, клиент в первой сессии…», «Допустим, вы тревожитесь перед встречей…». Без личных кейсов о реальных клиентах — приватность.
- Признание неоднозначности: «нет универсального ответа», «зависит от контекста», «в практике встречаются разные подходы». Это маркер эксперта vs. «фабрики уверенных лайфхаков».
- Лёгкая личная интонация Екатерины: «в моей практике», «я часто использую этот приём с клиентами», «когда мы говорим…».
- Метафоры — да, но **психологические**, не магические. «Карта работает как зеркало для подсознания», «как фильтр для размытых ощущений».

### Что нет

- Не «вы должны», «нужно», «обязательно». Только: «можно попробовать», «помогает», «один из подходов».
- Не клише: «в современном мире…», «как известно…», «всем хорошо известно…». Удалять без жалости.
- Не AI-mill маркеры:
  - ❌ Заголовок «N способов / N признаков / N правил» (см. [content-plan.md §0](content-plan.md#L19)).
  - ❌ Структура «Итак, поговорим о…» / «Прежде чем мы начнём…» / «В этой статье мы рассмотрим…». Сразу к делу.
  - ❌ «Важно понимать, что…», «следует отметить, что…», «таким образом…» — пустые связки, режем.
- Не идеализация продукта: «МАК решит любую проблему», «после колоды вы поймёте всё». Честно: МАК — инструмент, эффект зависит от запроса, опыта психолога, контекста.

### Эмоджи

Не используем. Никаких 🙏✨🌙. Только текст и плавный design.

## 5. SEO-требования

### Title (тег `<title>`)

- 60–65 знаков с учётом « — МакМагия» в конце.
- Содержит главный ключ кластера в неискажённой форме.
- Не дублирует H1 дословно — добавляет уточнение (год, цифру, выгоду).
- Не использует капс, не использует эмоджи.

Примеры:
- ✅ «Метафорические карты (МАК): что это и как работают — МакМагия»
- ✅ «МАК в работе психолога: техники, расклады, кейсы — МакМагия»
- ❌ «Узнайте о МАК-картах прямо сейчас!» (приманка, нет ключа).

### Description (`<meta name="description">`)

- 140–155 знаков. Конкретная польза + призыв читать.
- Содержит главный ключ + 1 околотематический.
- Без точек в конце (Яндекс/Google сами добавят).

### URL-slug

- Только латиница, kebab-case.
- 3–6 слов, без стоп-слов («и», «в», «для» — пропускаем).
- Содержит главный ключ в транслите.

Примеры:
- ✅ `/blog/chto-takoe-mak-karty`
- ✅ `/blog/mak-v-rabote-psihologa`
- ❌ `/blog/post-1`, `/blog/uznayte-o-mak-pryamo-seychas-2024`

### H1

- Один на странице.
- 6–12 слов, содержит главный ключ.
- Не дублирует title дословно (Title оптимизирован под выдачу, H1 — под читателя).

### H2/H3

- H2 — содержит подключи кластера. Например, в статье «Метафорические карты что это» — H2 «Виды колод МАК», «Чем МАК отличается от Таро», «Как работают МАК в кабинете психолога».
- H3 — детализация. Без ключевых слов в каждом H3 (это переоптимизация).

### Плотность ключей

Главный ключ — 4–8 раз в статье на 2000 слов. Распределён равномерно, не «в каждом абзаце». LSI/синонимы — органично.

**Перетинг ключей** запрещён: если из 2000 слов 50 раз встречается «метафорические карты» — статья на доработку.

### Внутренняя перелинковка

- Каждая статья ссылается на **3–5 других статей блога** в теле + 3–5 в related-блоке.
- Каждая статья ссылается на **1 коммерческую цель** (`/cards`, `/mac`, `/ai`, `/artterapy`) — в CTA внизу + 1 раз органично в теле.
- На provizorai.ru — только в релевантных статьях, 1 ссылка, в теле (не футер).

### Внешние ссылки

- 1–2 авторитетных внешних ссылки на исследования / классику (PubMed, APA, Cyberleninka, книги Юнга/Винникотта).
- `target="_blank" rel="noopener nofollow"` для всех внешних, кроме исследовательских (там без `nofollow` — это сигнал авторитета).

## 6. Заголовки — правила

### Что да

- Конкретная польза в заголовке: «Метафорические карты: как использовать в работе с тревогой».
- Вопросы — да, если они реально из выдачи Wordstat: «Как работают метафорические карты?», «Чем МАК отличается от Таро?».
- Указание целевой аудитории: «МАК для психолога», «МАК для родителей».

### Что нет

- ❌ «N способов / N правил / N признаков / N техник» — AI-mill маркер, понижение в выдаче.
- ❌ Кликбейт: «Вы не поверите, что покажут карты», «Этот приём изменит вашу практику».
- ❌ Капс, восклицания, эмоджи, «!!!».
- ❌ Гарантии результата: «100% работает», «гарантированно поможет».

## 7. E-E-A-T требования (особенно для YMYL-тем)

YMYL (Your Money or Your Life) для нас — статьи про тревогу, депрессию, выгорание, отношения, детскую психологию. Здесь требования жёстче.

### Обязательно для каждой YMYL-статьи

1. **Автор** — Каменская Екатерина, психолог. Карточка с фото, регалиями, ссылкой на профиль (b17 / instagram-альтернатива / сайт).
2. **Дата публикации + дата обновления** — обе видимы.
3. **Ссылка на источник** — минимум 1 на статью, на академический ресурс (APA, PubMed, Cyberleninka, книги).
4. **Дисклеймер для серьёзных тем** — депрессия, суицидальные мысли, психотравма: блок «Если вам тяжело сейчас» с телефоном горячей линии (8-800-2000-122 «Помощь детям», 988 США и т.п.) и фразой «статья не заменяет консультацию психолога».
5. **Не давать диагнозов в статье** — мы пишем «симптомы могут указывать на тревожное расстройство — нужна консультация специалиста», не «у вас тревожное расстройство, если N признаков».

### Что строго запрещено для YMYL

- ❌ Конкретные дозировки препаратов.
- ❌ Гарантии излечения.
- ❌ Советы про самолечение психо-фарма.
- ❌ Антинаучные методы (НЛП «как факт», расстановки Хеллингера как «доказанный метод», регрессии, био-программы и т.п.).

## 8. Перед публикацией — чек-лист агента

Прежде чем отдать статью на публикацию, агент проверяет:

- [ ] **Эзо-фильтр** (§1): прошёл поиском Ctrl+F по запретным словам — ни одного попадания.
- [ ] **Длина** соответствует типу статьи (§3).
- [ ] **Структура** соблюдена (§2): H1 + лид + оглавление (если >1500 слов) + H2-блоки + FAQ + CTA + related.
- [ ] **Title и description** заполнены, в пределах знаков (§5).
- [ ] **URL-slug** в kebab-case, без стоп-слов, с ключом в транслите.
- [ ] **Карточка автора** — Екатерина с регалиями.
- [ ] **3–5 внутренних ссылок** на другие статьи блога в теле + related-блок.
- [ ] **1 CTA** на коммерческую страницу.
- [ ] **1–2 внешние ссылки** на авторитетные источники (для YMYL — обязательно).
- [ ] **Иллюстрации** — 3–5 шт., все с alt-текстом, hero — для соц.сетей (OG image).
- [ ] **Тон** — без жаргона, без AI-mill клише, без эзо-маркеров.
- [ ] **JSON-LD Article** добавлен (или указано «верстальщику добавить»).
- [ ] **FAQ-разметка JSON-LD** добавлена (если есть FAQ-блок).
- [ ] Не использованы запрещённые форматы заголовков «N способов…».

## 11. Эскалация — когда агент должен спросить, а не угадывать

Агент **обязательно** возвращается с вопросом, если:

- Не уверен в формулировке термина (например, можно ли назвать МАК «проективной методикой» в конкретном контексте).
- Не уверен в этичности раскрытия темы (статья про суицид, тяжёлую травму, РПП — какой объём допустим, какие дисклеймеры).
- Не нашёл достоверного источника для YMYL-факта.
- Тема пересекается с эзо-кластером и непонятно, как её обойти (например, «МАК и Юнг про синхроничность»).

## 12. Формат работы Claude в этом проекте

Поскольку статьи пишутся прямо в чате со мной (Claude в проекте macmagia), а не через автономный pipeline:

**Бриф от пользователя:**
> «Напиши статью по теме №1 из semantic-core-analysis.md»
> — или —
> «Тема: МАК для нарциссического клиента. Ключ — `метафорические карты для психолога`. Длина 2500 слов. Автор — Екатерина.»

**Что я делаю:**
1. Читаю тему в content-plan.md / semantic-core-analysis.md.
2. Беру кластер ключей из `docs/seo/raw/wordstat-all-strict.csv`.
3. Для нашей ниши (МАК, арт-терапия, AI) — обязательно WebFetch ТОП-3 в выдаче, чтобы видеть актуальные тренды.
4. При сомнениях — спрашиваю до написания (см. §11).
5. Пишу — либо прямо в чат, либо в файл `docs/seo/articles/<slug>.md` (договариваемся в начале).
6. После — прохожу чек-лист [agent-task.md §10](agent-task.md) и отчитываюсь: количество слов, главные ключи, ссылки, замечания.
7. Жду ваших правок.

**Пока блога нет** (он в плане — `lk.macmagia.ru/blog/` или `macmagia.ru/blog/`) — статьи накапливаются в `docs/seo/articles/`. Когда движок будет готов — массово закоммитим.
