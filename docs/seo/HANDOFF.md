## WORKFLOW (как всё устроено — КРИТИЧНО)
- Статьи = markdown в `docs/seo/articles/<slug>.md`. **Править .md, НЕ `blog/*.html`** (HTML генерится сборкой и затирается).
- Сборка: `python3 scripts/build_blog.py` → рендерит blog/*.html, blog/index.html, обновляет sitemap.xml, встраивает Я.Метрику.
- Деплой: `git add ... && git commit && git push origin main` → GitHub Actions сам выкатывает (~50с). Проверка статуса: `gh run watch $(gh run list --limit 1 --json databaseId -q '.[0].databaseId') --exit-status`.
- **После деплоя на бою сначала 404 из-за кэша** — проверять с cache-bust: `curl -s -o /dev/null -w "%{http_code}" "https://macmagia.ru/blog/<slug>.html?v=$(date +%s%N)"` (повторить 2-3 раза до 200).

## ЖЁСТКИЕ ПРАВИЛА (нарушение = откат/переделка)
1. **ПРАВИЛО №0:** НИКОГДА не писать статью без проверки ключей в Wordstat. Сначала собрать частоты → проверить спрос+каннибализацию → потом писать. НЕ предлагать «пиши без ключей» даже под «давай». (Память: seo-wordstat-before-writing.)
2. **Эзо-фильтр:** сборка падает на словах магия/магическ, волшебн, гадание/гадать, таро, руны, гороскоп, астролог, эзотерик, предсказани/предсказать, карма, чакр, биополе, «привлечение денег/любви», «исполнение желаний», «послание вселенной», «карта дня» — даже в отрицании. Синоним «гадания» → «угадывание/готовый ответ извне», «эзотерики» → «мистика».
3. **Анти-AI** (`docs/seo/edit-brief-stylistic.md`): антитез «не X, а Y» ≤2 на статью; без «парадокс», «две стороны медали»; разные лиды (не тройные реплики подряд); не повторять CTA-хвост «в безопасном темпе и с сопровождением».
4. **Буквица:** лид НЕ начинать с однобуквенного предлога (С/В/К/О/У) — CSS drop-cap склеит «С утра»→«Сутра».
5. **Список в .md** — пустая строка перед буллетами (иначе склейка в абзац).
6. **Safety:** в темах с риском (суицид-мысли/насилие/РПП/горе/паника) — рамка «к специалисту» + телефон **8-800-2000-122**. Клинические темы (панические атаки, страх смерти, ПТСР) — НЕ брать как статьи.
7. **Эзо-медитации** (привлечение денег/любви/желаний, род/предки, вселенная) — НЕ брать в блог.
