# Маркерные ключи для сбора семантики (план на 700 статей)

Составлено 31.08.2026. Это **не список статей**, а seed-фразы для Вордстата: каждая
раскрывается в десятки запросов, из которых уже отбираются темы. Порядок блоков — по
отдаче, а не по объёму.

**Перед сбором свериться с реестром** `docs/seo/ключи-разбор.md` и с 158 готовыми
статьями, иначе половина тем окажется дублями.

**Правило №0 из HANDOFF действует:** ни одной статьи без проверки частотности.
Отбирать по частоте «!запрос» (точная форма), а не по общей — общая врёт в разы.

**Запрещено брать в любом блоке** (сборка упадёт на эзо-фильтре): магия, волшебство,
гадание, таро, руны, гороскоп, астрология, эзотерика, предсказания, карма, чакры,
биополе, «привлечение денег/любви», «исполнение желаний», «послание вселенной»,
«карта дня».

## Как считать частотность

1. Вордстат → регион Россия → «!фраза» в кавычках с восклицательным знаком: даёт
   точную форму без словоформ и хвостов.
2. Отбирать в работу: **от 50 показов в месяц** по точной форме. Ниже — только если
   запрос коммерческий (МАК, курсы) или закрывает дыру в кластере.
3. Сразу смотреть правую колонку Вордстата — «похожие запросы»: оттуда берутся темы,
   которых нет в этом списке.
4. Проверять каннибализацию: если запрос уже покрыт статьёй из реестра — не брать.
