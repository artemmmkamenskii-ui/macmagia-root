## 0. Главный принцип позиционирования

Бренд называется «МакМагия», и это **единственное** место, где допустимо слово «магия». Весь контент позиционирует продукт как **психологический инструмент**, а не эзотерику. Это и SEO-защита (не скатиться в кластер таро/гадания, см. §1 donors-shortlist), и E-E-A-T: автор — Екатерина Каменская, психолог, выпускница психфака МГУ.

**Правила контента:**
- Термин: «метафорические ассоциативные карты (МАК)», а не «магические карты», не «гадальные карты».
- Никаких «предскажет будущее», «расскажет судьбу», «гадание на картах». Только: «помогает осознать», «запускает ассоциации», «инструмент рефлексии и диагностики».
- У каждой статьи — автор с регалиями (Екатерина), дата, источники. Это отстраивает от AI-mill контент-фабрик типа 5psy.ru (см. стоп-лист).
- ❌ Не использовать заголовки-паттерны AI-mill: «N способов…», «N признаков…», «как не пропустить…». Яндекс/Google понижают этот класс.

## 1. Семантические кластеры

### Кластер A — Информационный (МАК «что это», самый широкий вход)
Аудитория: оба. Низкая конкуренция, верх воронки.
- метафорические ассоциативные карты / МАК-карты / что такое МАК
- как работают метафорические карты
- виды (колод) метафорических карт
- метафорические карты для самопознания

### Кластер B — Профессиональный (психологи)
Аудитория: специалисты. Коммерчески ценный — ведёт к курсам.
- МАК в работе психолога
- обучение метафорическим картам / курсы МАК для психологов
- расклады / техники работы с МАК
- арт-терапия обучение / техники арт-терапии
- как создать свою колоду МАК (+ с помощью нейросетей)
- МАК для работы с детьми / парами / запросом

### Кластер C — Коммерческий (покупка)
Аудитория: оба. Низ воронки → `/cards`, Wildberries.
- колоды МАК купить / электронные (цифровые) колоды МАК
- печатные колоды МАК
- МАК онлайн / работать с МАК онлайн

### Кластер D — Клиентский / саморазвитие (конечные клиенты)
Аудитория: клиенты. Доноры — популярная психология, лайфстайл.
- метафорические карты для себя / самостоятельно
- упражнения для самопознания / саморефлексии
- как разобраться в эмоциях / чувствах
- метафорические карты для постановки целей

## 1.5. Лид-магнит и продуктовые идеи (из анализа МАК-конкурентов)

**Из mak-competitors-analysis §5** — критический инструмент для SEO и конверсии:

1. **Бесплатный онлайн-расклад МАК с расшифровкой** на macmagia (по образцу online.metaforicheskie-karti.ru). Главный лид-магнит сегмента; без него мы слабее всех CLEAN-конкурентов. **Чистым психо-языком**, чтобы перебить эзо-сервисы k-s-art/kit-jobs. Предложение для дизайна: страница `/mak-online` с виртуальной колодой, после первого расклада CTA «получить полную колоду / записаться на курс».

2. **SaaS-платформа МАК для онлайн-сессий** (по образцу macroom.online). Психолог раздаёт клиенту ссылку, оба видят колоду на экране, расклад фиксируется в карточке клиента. Прямой мост к provizorai.ru (документация после сессии с МАК).

3. **Курс «Своя колода МАК через нейросети»** — уже есть на `/ai`. Нужно усилить SEO-страницу и добавить статью-руководство (#16 в списке тем выше).

4. **Подписка «колода месяца» / pdf-колоды для печати** — цифровая модель, отсутствует у всех МАК-конкурентов.

5. **Авторские художественные колоды от художника** (semantica.store-формат) — не репродукции, а собственные иллюстрированные серии.

Глоссарий (опционально, позже): короткие страницы-термины (МАК, проективные методики, арт-терапия, метафора в психологии, OH-карты, проекция, ассоциативный ряд) — аналог `/glossary` provizorai, под низкочастотные запросы.

## 3. Внутренняя перелинковка

- Pillar-статьи (1, 2) ↔ остальные статьи кластера.
- Каждая статья → 1 коммерческая цель (`/cards`, `/mac`, `/ai`, `/artterapy`).
- Кросс-линк на provizorai — только в релевантных статьях (2, 5), 1 ссылка, в теле. См. §5 donors-shortlist.
- Из лендинга добавить ссылку на блог в шапку/футер, когда блог появится.

## 4. Технические заметки

- Блог желательно на том же домене (`macmagia.ru/blog/...`), не на поддомене — весь ссылочный вес на один хост.
- У каждой статьи: уникальные title/description, OG, JSON-LD `Article` с `author` (Екатерина) и `publisher` (МакМагия, тот же `@id`, что в `index.html`).
- Добавлять новые URL блога в `sitemap.xml`.
- Перед закупкой ссылок на статью — статья должна быть опубликована и проиндексирована.
