## 1. Контекст проекта

**МакМагия (macmagia.ru)** — бренд-хаб, который объединяет:
- **Метафорические ассоциативные карты (МАК)** — авторские колоды (печатные и цифровые) + обучение работе с МАК.
- **Арт-терапия** — курсы, техники, методики.
- **AI в работе психолога** — связка с продуктом `provizorai.ru` (документация сессий).
- **Психология для конечных клиентов** — поп-психология, эмоции, отношения, самопознание.

### Целевая аудитория — двойная

1. **«Психологи» (специалисты, профи).** Приходят за курсами, методиками, инструментами для работы. Покупают: курсы (`/ai`, `/artterapy`, `/mac`), консультации, профессиональные колоды.
2. **«Клиенты» (саморазвитие).** Приходят за разбором эмоций, тестами, практиками для себя. Покупают: цифровые/печатные колоды (`/cards`), массовые курсы для себя.

В каждой статье должна быть понятная аудитория. Может быть смешанная (большинство pillar-статей), но один основной адресат всегда есть.

### Авторство — два голоса

#### Голос 1. «Екатерина Каменская — старшая коллега за чашкой чая»

Применяется к: **проф-статьям** (работа с клиентом, методики МАК, техники), **продуктовым посадкам** (как использовать наши колоды), **разборам кейсов**.

- **Автор — Екатерина Каменская, психолог, выпускница психфака МГУ, основатель МакМагии.** От первого лица: «Я», «у меня», «когда я начинала», «в моей практике».
- Тёплый, доверительный, разговорный тон. Как если бы рассказывала младшей коллеге за чашкой чая.
- К читателю — на «вы», уважительно.
- Опирается на личный опыт. Истории, наблюдения, признания собственных ошибок («я сама долго пыталась…»). Без академического канцелярита.
- Конкретные примеры — на вымышленных клиентах: имя + краткий контекст («клиентка Мария, 32 года, запрос — тревога перед собеседованиями»). **Никаких реальных кейсов.** Inline-пометка «вымышленный персонаж» в проза-тексте не нужна — это сбивает ритм.
- Никаких «волшебных обещаний» от карт. МАК — инструмент рефлексии и проекции, не предсказатель и не магия.
- Без снисхождения. Если адресат — коллега, не объяснять базовые психо-термины (проекция, перенос, рабочий альянс — даём ссылки на глоссарий).
- Сдержанная эмоциональность. Можно «я была в растерянности», «мне это казалось бессмысленным» — без драматизации.

#### Голос 2. «Редакция МакМагии»

Применяется к: **массовому поп-психо** (что такое тревога, депрессия, СДВГ — для конечных клиентов), **обзорам тестов**, **глоссарным справкам**, **новостным/инфо-статьям**.

- **Автор подписи** — «Редакция МакМагии» (`authorSlug: macmagia-editorial`).
- Стиль — журналистский, объяснительный, с ясной структурой. «Простыми словами», без академизма.
- К читателю — на «вы».
- Опирается на источники (исследования, классику), а не на «личный опыт».
- Подразумевается, что текст вычитан Екатериной как психологом — это маркер E-E-A-T, который указываем в карточке внизу статьи: «Материал подготовлен редакцией МакМагии и проверен Екатериной Каменской, психологом».
- **Никакого тона «эксперта-всезнайки».** Никаких «нужно понимать», «обязательно запомните», «многие психологи говорят». Только: «исследования показывают», «по нашим наблюдениям в работе», «коллеги-психологи рекомендуют».

### Когда какой голос — таблица решений

| Тип статьи | Автор |

| МАК в работе психолога / техники / кейсы | Екатерина |
| Арт-терапия — методики / упражнения для специалистов | Екатерина |
| AI для психолога — этика / инструменты | Екатерина |
| Создание колоды МАК через нейросети | Екатерина |
| Что такое МАК / арт-терапия — pillar | Екатерина |

| Обзоры психо-тестов / типов привязанности | Редакция |
| Архетипы Юнга / классические концепты | Редакция |
| Подборки книг / обзоры методов терапии | Редакция |
| Глоссарные короткие справки | Редакция |

## 2. КРАСНАЯ ЛИНИЯ — эзо-фильтр (нарушение = отказ от публикации)

В бренде содержится слово «Магия». В выдаче по МАК-запросам соседи — таро, гадания, руны. Это **главный риск проекта**: скатиться в эзотерический кластер Яндекса → потеря YMYL-trust → потеря всей выдачи.

### 2.1. Запрещённые слова и формулировки

Ищем поиском по тексту перед публикацией. Найден хоть один — статья на доработку.

**Запрещённые слова (точечные):**
- «магия», «магический», «магически», «волшебно», «волшебство»
- «гадание», «гадать», «гаданье», «нагадать»
- «таро», «руны», «руна», «гороскоп», «астрология», «нумерология», «хиромантия»
- «эзотерика», «эзотерический», «эзотерик»
- «предсказание», «предсказать», «прорицать», «прорицание»
- «карма», «кармический»
- «энергия» в эзо-смысле, «энергетика человека», «биополе», «чакры», «чакра»
- «ангелы», «архангелы», «высшие силы», «вселенная говорит», «послание Вселенной»
- «знак свыше», «знаки судьбы»
- «синхроничность» — допустима **только** с явной ссылкой на Юнга и в академическом контексте, не как поп-эзо
- «привлечение денег», «привлечение любви», «исполнение желаний», «портал», «магический ритуал»

**Запрещённые формулировки:**
- «карты подскажут судьбу»
- «откроет тайны», «раскроют истину», «прочитают будущее»
- «карты знают», «карты говорят» (вместо: «карта помогает осознать», «изображение запускает ассоциацию»)
- «магически», «волшебным образом», «чудесно»
- «карта дня», «расклад на месяц», «расклад на будущее» — звучит как таро

### 2.2. Что говорим вместо

- ✅ «Метафорические ассоциативные карты (МАК)» — полное название при первом упоминании. Далее: «МАК», «карта», «изображение», «метафорическая карта», «колода».
- ✅ «Помогает осознать», «запускает ассоциации», «активирует внутренний диалог», «инструмент рефлексии», «проективный метод», «диагностический инструмент», «помогает сформулировать запрос».
- ✅ «Психологический инструмент», «арт-терапевтический приём», «техника работы с клиентом», «упражнение для самопознания».
- ✅ В контексте Юнга — допустимы «архетип», «символ», «коллективное бессознательное», «индивидуация», «синхроничность» — **только** с академической ссылкой (Юнг, Хиллман, Эдингер), не в массовом эзо-смысле.

### 2.3. Сравнение МАК с Таро — особый случай

Допустимо **только** в отстраивающем ключе. Есть отдельная статья-pillar [content-plan.md #9 «Чем МАК отличается от Таро»](content-plan.md), где мы прямо различаем:

- МАК — психологический инструмент, проективная методика.
- Таро — мантическая система, используется для гаданий.
- Это разные практики, разные традиции.

**Если в любой другой статье упоминаем Таро — только в отстраивающем контексте, со ссылкой на pillar-статью.** Никогда: «МАК — это современное Таро».

### 2.4. Доноры и площадки

Когда статья будет размещена как гостевая — площадка не должна быть из эзо-кластера (см. [donors-shortlist.md §1](donors-shortlist.md)). Это не задача копирайтера, но если по теме статьи донор подразумевается из эзо-сегмента — флаг в эскалацию.

## 3. Язык — только русский

Весь связный текст по-русски, включая пояснения к аббревиатурам. Английские вставки в проза-тексте недопустимы.

### Что заменять

| Не пишем | Пишем |
|---|---|
| how-to, practical-guide, deep dive | руководство, практический разбор, глубокий разбор |
| MAC (Metaphorical Associative Cards) | МАК (метафорические ассоциативные карты) |
| OH cards | ОХ-карты (если упоминаем колоду оригинала — даём пояснение «оригинальная колода Моритца Эгетмайера, 1980-е») |
| CBT, ACT, MBCT | КПТ, ACT (терапия принятия и ответственности), MBCT (когнитивная терапия на основе осознанности) |
| acting out, burnout | отыгрывание, выгорание |
| mindfulness | осознанность (mindfulness в скобках при первом упоминании, если стилистически уместно) |
| insight | инсайт (укоренилось в русском) |

### Что можно оставлять по-английски

- Имена брендов и продуктов: ChatGPT, Claude, Midjourney, Whisper, Notion, Macmagia (бренд), Provizor AI.
- Международные шкалы: PHQ-9, GAD-7, BDI-II, MBTI, Big Five. Перевод даём один раз в скобках при первом упоминании, дальше — аббревиатура.
- EMDR, ACT, REBT, CBT — устоявшиеся англо-аббревиатуры психо-методов. Расшифровка по-русски в скобках при первом упоминании.

**Принцип:** русскоязычный читатель должен прочитать статью без переключения языкового контекста. Если встречает английский — это либо имя продукта, либо клиническая аббревиатура, которую он узнаёт.

## 3.5. Согласованность с серией Provizor AI — эмпирический статус метода

В сестринском проекте `provizorai.ru` ([writer-brief](../../../Приложение%20для%20психологов/docs/content/writer-brief.md), [agent-task §1.3 / §1.6](../../../Приложение%20для%20психологов/docs/content/agent-task.md)) установлена высокая планка академической добросовестности: эмпирический статус каждого метода называется честно. Если читатель встретит обе серии, **разрыв в планке будет заметен.** Поэтому те же правила работают и для macmagia.

### Главное правило: статус метода — честно, в основном тексте, без сокрытия

Если в статье описывается терапевтический или диагностический метод (КПТ, EMDR, ACT, схема-терапия, психоанализ, гештальт, песочная терапия, сказкотерапия, арт-терапия, **МАК**, нейрографика и т.п.) — **обязательно** один абзац о его эмпирическом статусе.

**Шаблон формулировок по уровню доказательности:**

| Метод | Что писать |
|---|---|
| КПТ, EMDR, IPT | «Доказательный метод с обширным эмпирическим корпусом, входит в международные клинические рекомендации». Со ссылкой на NICE / APA / ВОЗ. |
| ACT, MBCT, схема-терапия | «Доказательный метод, эмпирическая база меньше, чем у КПТ, но накоплена за 20+ лет исследований». Ссылки на метаанализы. |
| Психоанализ, психодинамическая терапия | «Историческая школа со столетней практикой. Доказательная база ограничена; в современных метаанализах эффективен при определённых показаниях». |
| Гештальт-терапия, психодрама | «Признанные клинические методы, психометрической валидизации ограниченной; работают как рабочая клиническая практика». |
| **МАК, арт-терапия, песочная терапия, сказкотерапия, нейрографика** | **«Психометрической валидизации не имеют. Это рабочая клиническая практика и консультативный инструмент, не доказательный метод в строгом смысле».** |
| Расстановки Хеллингера, регрессии, био-программы, НЛП | **Не описывать как доказательные методы.** Если упоминаем — только в критическом контексте или для пояснения, чем мы НЕ занимаемся. |

### Что НЕ писать

- ❌ «МАК признаны как профессиональный инструмент» — без оговорки про валидизацию это создаёт у читателя ложное впечатление о статусе.
- ❌ «По МАК пишутся диссертации, есть программы повышения квалификации» — формально верно, но провоцирует ложную ассоциацию со статусом доказательных методов.
- ❌ «МАК — мягкая разновидность Роршаха / ТАТ» — это разные регистры (диагностический инструмент со стандартами vs рабочий инструмент для разговора). Уравнивание — методологическая ошибка.

### Что писать вместо

- ✅ «МАК закрепились как профессиональный консультативный инструмент с собственными школами. Психометрической валидизации у них нет — это рабочая клиническая практика, не доказательный метод».
- ✅ «На том же общепсихологическом феномене (проекция на неоднозначный стимул) построены Роршах и ТАТ, но регистры разные: у них есть стандартизированное предъявление и системы оценки, у МАК — нет».

### Когда вставлять

В **основной текст** (не в FAQ, не в сноску), в раздел «что это» или «как работают», коротким абзацем. Один раз на статью. Не повторяем в каждом блоке.

## 3.6. Работа с травмой и обход защиты — обязательные оговорки

Это вытяжка из ревизии серии Provizor AI (схема-терапия, EMDR, ПРЛ, сензитивные темы) и пилотной статьи macmagia. В коммерческом блоге МакМагии планка обязательно та же самая.

### 3.6.1. Работа с травмой через МАК/арт-терапию

Если в статье упоминается работа с травматическим материалом через МАК, арт-терапию, песочную терапию, сказкотерапию — **обязательная оговорка:**

> МАК (или другой проективно-творческий инструмент) — не самостоятельная травмотерапия. Это инструмент в **фазовом подходе**: на этапе стабилизации, работы с ресурсом, дистанцированного знакомства с темой. Глубокая работа с травматическим материалом требует профильной подготовки (EMDR, нарративная экспозиция, фазовый подход Boon — van der Hart — Steele) и устойчивого терапевтического альянса.

Без этой оговорки читатель-психолог без профильной подготовки может прочитать статью как «вот, МАК — рабочий инструмент при травме, можно использовать». Это потенциально вредно.

### 3.6.2. «Обход защиты» через метафору

Распространённая в МАК-сообществе формулировка «карта снимает защиту» / «метафора снимает фронтальную атаку» — **клинически проблематична** без оговорки. Защита бережёт клиента от того, к чему он не готов.

**Правильно:**

> Метафора создаёт обходной путь к материалу, но **не самоцель «снять защиту любой ценой»**. Защита работает безопасно только при устойчивом терапевтическом альянсе и в темпе клиента, с правом остановиться в любой момент. Особенно осторожно — в работе с травмой и пограничной структурой, где быстрое продвижение через метафору может дать декомпенсацию.

### 3.6.3. Скорость работы

Если в статье упоминается «ускоренный доступ к материалу через МАК/арт-терапию» — добавлять, что:
1. Первые сессии «разговорной терапии» — это не «топтание», а собственно работа по построению альянса и сбору материала (особенно в психодинамическом подходе).
2. Ускоренный доступ имеет обратную сторону: клиент может быстро выйти на тему, с которой пока не готов работать. Задача психолога — замедлиться, а не «развить успех».

## 4. Точность утверждений (E-E-A-T для YMYL)

macmagia — пограничный YMYL. Темы про тревогу, депрессию, выгорание, детскую психологию, отношения — требуют точности на уровне «не повредит читателю».

### 4.1. Эмпирические утверждения — со статусом доказательности

Категоричные «исследования показывают», «эмпирически доказано» без оговорок — недопустимы.

- ✅ «По данным метаанализа [ссылка], эффект-сайз умеренный»
- ✅ «По имеющимся данным, связь есть, но размер эффекта спорный»
- ✅ «По части исследований», «дискуссионно», «есть разные оценки»
- ❌ «Доказано, что МАК помогают при тревоге» — без источника не пишем
- ❌ «Все психологи согласны, что…» — не пишем (нет «всех»)

### 4.2. Статистика и цифры

Если приводим процент, диапазон, размер выборки:
- **либо** даём ссылку на источник,
- **либо** пишем «по разным оценкам, X–Y%» с пояснением, от чего зависит разброс.

Не приводить ровную цифру как факт без референса.

### 4.3. Психотерапевтические техники — в рамках школы-источника

Если в статье упоминаем технику — она привязана к своей модальности. Расширительное использование — явно помечать.

**Конкретные правила:**

- **Окно толерантности** (Siegel) — конкретный концепт из trauma-informed терапии. Не использовать как метафору «зоны комфорта».
- **ABC** (Эллис, REBT) — B = иррациональные убеждения. Не путать с автоматическими мыслями Бека (когнитивная терапия). Если в статье кейс КПТ — B = мысль, но это допустимое рабочее расширение, пометить.
- **Контрперенос** (психоанализ) — реакция терапевта на проекции клиента. В КПТ — «эмоциональная реакция терапевта», не контрперенос.
- **Поведенческий эксперимент** vs **экспозиция** в КПТ — разные техники с разной логикой.
- **«Горячий стул»** (психодрама) vs **«пустой стул»** (гештальт) — разные техники, не синонимы.

**Правило:** перед использованием техники сверять с её школой-источником. Если в нашей модальности термин обозначает другое — либо переименовать, либо явно оговорить расширительное использование.

### 4.4. Граница компетенции

В отличие от provizorai, у нас не клинический сайт. Но всё равно:
- Психолог-немедик не ставит диагнозов по МКБ. В статьях про ПРЛ, НРЛ, ОКР, СДВГ — феноменологическое описание, а не «приписывание кода клиенту».
- Психолог не назначает препараты. Если упоминается лекарство — формат «к психиатру, который может назначить препарат», без названий и схем.
- Гипотезы и наблюдения — да. Диагнозы и назначения — нет.

### 4.5. Чувствительные темы (триггер-предупреждение)

Для статей про:
- суицидальные мысли, самоповреждения;
- тяжёлую психотравму, ПТСР, КПТСР;
- РПП (расстройства пищевого поведения);
- насилие — партнёрское, детское, сексуальное;
- зависимости;
- шизофрения и психозы.

— в начале статьи **блок-предупреждение**: «Эта статья содержит описание [темы]. Если для вас это болезненная тема — можно отложить чтение или обратиться к специалисту».

И **внизу статьи** — горячая линия:
- 8-800-2000-122 — детский телефон доверия.
- В острой ситуации — звонить 112.

## 5. Антимаркеры AI-стиля

Эти конструкции выдают AI-руку даже в осмысленном тексте. **Сводим к минимуму или удаляем.**

### 5.1. Структурные клише

- **«Не X, а Y»**, **«Это не X — это Y»**, **«X — это не A, X — это B»** — **максимум 2 на статью**, причём только в местах, где антитеза несёт методическую нагрузку (разведение клинических состояний, статус метода, граница нормы и сигнала). Остальные переписываем в обычные утверждения.
  - **Правило обязательной самопроверки** перед сдачей: открыть редактор, сделать поиск по `не ` и пройтись по каждому вхождению. Считать формы «это не X», «не X — это Y», «не X, а Y», «X — не A. X — B», финальные «не про X. Это про Y». Если получилось больше 2 — половину рассосать в позитивные утверждения.
  - **Скрытая ловушка стиля.** В МакМагии есть редакторский голос, в котором проще всего формулировать через контраст. Это **не повод нарушать лимит**. Если статья естественно «думает» противопоставлениями — оставьте 1-2 самые сильные (там, где они работают как клинический разворот), остальные подайте утверждениями: «Главный навык здесь — умение возвращаться» вместо «Не сдаваться — это не про силу воли. Это про умение возвращаться».
  - **Серии противопоставлений** в одном абзаце («Не "похудеть", а "ходить по лестнице". Не "найти работу", а "перестать ехать туда"») считаются как несколько штук и складываются в лимит §5.1, даже если построены как ряд примеров.
- **«Ключ — динамика»**, **«Ключ — содержание»** и подобные риторические колон-связки — не использовать.
- **Числа с плюсом** («5+ пунктов», «3+ балла») — писать «5 и более».
- **«Принципиально / принципиальное отличие»** — максимум 1 на статью.
- **Афористичные финалы абзацев** («Это вопрос компетенции и безопасности», «Это меняет всё») — максимум 1 на статью.
- **Парные тире вокруг вставок** («X — Y — Z» в каждом абзаце) — где можно, заменять на запятые или точки с запятой.

### 5.2. Канцелярские зачины (удалять)

- «В современной психологии…»
- «Стоит отметить, что…»
- «Важно понимать, что…»
- «Многие специалисты согласны, что…»
- «Прежде чем мы начнём…»
- «В этой статье мы рассмотрим…»
- «Итак, поговорим о…»

Начинаем сразу с сути.

### 5.3. Шаблонные финалы

❌ **Не использовать как формулу:**

«Если вы хотите глубже разобраться в работе с МАК — приглашаем на наш курс. Подробнее в нашем глоссарии Y.»

Каждой статье — свой финал по содержанию. Финал — это завершённая мысль, а не CTA-шаблон.

### 5.4. Триадные списки везде

Списки из ровно трёх пунктов в каждом абзаце — узнаваемый AI-ритм. Где-то делаем 2, где-то 4, где-то прозой.

### 5.5. Образные клише

- «Топливный бак тревоги»
- «Тело сидит — мозг бегает»
- «Маркёрная защита»
- «Режет реальность»
- «Нанизывается депрессия»
- «Карта-зеркало души» (особенно опасно — почти эзо)

Заменять на нейтральные психологические формулировки.

### 5.6. Кавычки-цитаты клиента — экономия

«я не помню», «всю жизнь так», «как с моторчиком», «не могу выключить голову» — 2–3 на статью, не больше. Это маркер AI-«живого» стиля при перенасыщении.

### 5.7. «В кабинете видно/слышно/буквально»

Максимум 1 на статью. AI любит этот оборот для имитации живого опыта.

### 5.8. Финальная проверка анти-AI

Перед сдачей — пройти статью с этим списком в руке. На каждый пункт — посчитать количество.

Если статья «звучит как LLM» — переписать «голосовые» куски: добавить личную интонацию (для статей Екатерины) или академическую сдержанность (для статей редакции).

### 5.9. Pullquote-выноски — разные формы

В нашем шаблоне типично 1–2 декоративных pullquote-выноски на статью. **Правило:** если выноски две — они должны быть в **разных риторических формах**. Не обе антитезы, не обе афоризмы-противопоставления.

**Плохо** (всё одна формула — антитеза):
> «МАК не заменяют разговор. Они дают форму тому, что не нашло слов.»
> «МАК в работе с травмой — это инструмент стабилизации. Не самостоятельная травматерапия.»

**Хорошо** (разные формы — антитеза + личная норма):
> «МАК дают форму тому, что уже есть внутри, но к словам пока не пришло.»
> «У меня тихое правило: если за сессию мы вытянули больше четырёх карт — скорее всего, я прячусь за инструментом.»

Допустимые формы pullquote:
- одна антитеза (максимум одна на статью);
- личная норма автора («у меня правило...», «я держу в голове...»);
- конкретное наблюдение из практики («клиент чаще всего...»);
- риторический вопрос (умеренно);
- цитата эксперта.

Если в статье уже работает антитеза в pullquote — вторая выноска должна быть в **другой форме**.

### 5.10. Тезисный повтор — максимум два раза

Один и тот же тезис, повторённый в разных формулировках 3+ раз, читается как риторическое усиление через повтор — типичный AI-маркер. **Лимит:** максимум **два раза** на статью один тезис (в лиде/введении и в заключении — допустимо; в трёх средних разделах — уже плохо).

**Пример из правки.** В статье «Чем МАК отличаются от Таро» тезис «это разные поля / разные регистры» встречался 4–5 раз — в первом абзаце, после таблицы, в разделе про «современное Таро», и в заключении. Переписать: оставить **в первом абзаце и в заключении**, в средних разделах — сразу делать содержательное различение, без повторного объявления.

### 5.11. Сравнительные статьи — серия противопоставлений суммируется с §5.1

В статьях формата «X vs Y» (например, «МАК vs Таро», «КПТ vs психоанализ») по природе много противопоставлений. **Это не обнуляет лимит §5.1** на «не X, а Y». Серия из 5–7 строк сравнительной таблицы — это уже **5–7 антитез** в восприятии читателя.

**Правило для сравнительных статей:**
- В табличном сравнении противопоставления допустимы (это формат таблицы).
- В **связном тексте вокруг таблицы** — лимит §5.1 действует: не более 1–2 «не X, а Y» в прозе.
- Не дублировать выводы таблицы антитезами в прозаических разделах. Если в таблице уже «МАК — психологическая методика; Таро — мантическая система», в прозаическом разделе НЕ повторять эту антитезу — описывать каждую сторону отдельно, без «не А, а Б».

### 5.13. Семантика — обязательный шаг ПЕРЕД написанием

Статья не начинается с заголовка-смысла. Статья начинается с **семантической карты**, в которой каждый H1/H2 явно мапится на конкретный поисковый запрос с подтверждённой частотностью. Без этой карты статью не пишем — она структурно слепая, попадёт по одному запросу из десяти.

**Процесс перед написанием (обязательный):**

1. **Head-запрос → title и H1.** Берём один основной запрос с максимальной частотой в теме (≥300 показов/мес в идеале, ≥100 — допустимо). Title и H1 формулируем под него **дословно** или с минимальным переносом.

2. **Топ-подзапросы с частотами → H2 дословно.** Собираем 6–10 кандидатов в длинный хвост: проблемные формулировки («почему не получается X»), методические («техники X», «как сделать X пошагово»), варианты (синонимы, акронимы вроде «smart цели»), эмоциональные («что делать когда X не работает»). Каждый кандидат проходит проверку в Wordstat. Те, у кого volume ≥30 — становятся **H2 дословно** или с минимальной перефразировкой. Те, что ниже — выкидываем или сводим в один абзац под общим H2.

3. **Сравнения → таблицы.** Длинный хвост «чем X отличается от Y», «X или Y что выбрать» собирается в **сравнительную таблицу** (наш блок `article__table`). Каждая строка таблицы должна быть запросом — это плотный формат для длинного хвоста.

4. **Фильтр перед утверждением списка.** Выкидываем:
   - **омонимы и нерелевантные значения** (например, «цели жизни» в значении «расставить мебель в детской по фен-шуй»);
   - **навигационные** («как достичь целей сайт», «достижение целей вконтакте» — там ищут конкретные ресурсы);
   - **клиентские vs профессиональные несоответствия** (под клиентский продукт не брать профессиональные запросы и наоборот);
   - **YMYL-мины** (запросы вроде «как лечить депрессию» — это поле для специалистов по доказательной медицине, не для коммерческого блога с курсами).

5. **Frontmatter обязательно содержит подтверждённую семантику.** Без этого блока статья не собирается:

   ```yaml
   primaryKeyword: как достичь целей
   primaryVolume: 9212
   queriedAt: 2026-06-15
   queryMap:
     - q: как достичь целей
       v: 9212
       role: H1
     - q: как поставить цели правильно
       v: 1234
       role: H2
     - q: почему не получается достичь целей
       v: 567
       role: H2
     - q: техники достижения целей
       v: 432
       role: H2 (как таблица методик)
     - q: цели на год как составить
       v: 890
       role: H2 (сезонный декабрь-январь)
     - q: что мешает достичь цели
       v: 320
       role: H3 внутри «почему не получается»
   ```

6. **Закрытие петли — после написания.** В конце статьи проверяем: каждый H1/H2 из `queryMap` явно представлен в тексте дословно или с минимальной перефразировкой. Если H2 в плане был «как поставить цели правильно», а в тексте написано «принципы целеполагания» — переписать H2 под формулировку из Wordstat.

**Что НЕ делаем:**

- ❌ Заголовок-смысл без проверки семантики («МАК в работе с нарциссической организацией клиента» — умно звучит, но не запрос).
- ❌ Один высокочастотный запрос как title без поддержки в H2-структуре. Это даёт сильную позицию по одной фразе и теряет десяток околотематических.
- ❌ H1, H2 «художественно» — переформулированные, теряющие точное совпадение со запросом. Точное совпадение ключа в H2 (заодно отбойником под FAQ schema) даёт +20–30% к ранжированию длинного хвоста.

### 5.14. FAQ не дублирует тело

Ответ в FAQ-блоке **не должен** пересказывать абзац основного текста почти дословно. Это типичная SEO-практика, но в нашей рамке она читается как «AI размазал текст». Допустимые роли FAQ:
- закрыть вопрос, который не попал в основной текст;
- дать **сжатый** ответ (1–3 предложения) на вопрос, который в теле раскрыт длиннее;
- ответить на ракурс, не описанный в теле (например, «с какого возраста...», «можно ли онлайн...»).

**Не делать:** FAQ-ответ — это сокращённый пересказ раздела основного текста с теми же примерами. Если такая ситуация возникает — либо переписать FAQ под другой ракурс, либо удалить пункт.

## 6. Структура и объём статьи

### 6.1. Длина по типу

| Тип | Длина |
|---|---|
| Pillar (опорная) — что такое МАК / арт-терапия / AI-психология | **2500–4000 слов** |
| Стандартная блог-статья | **1500–2500 слов** |
| Глоссарная статья (термин) | **400–800 слов** с плотной перелинковкой |
| Лендинг психо-теста | отдельная страница теста + статья «что такое X» 1000–2000 слов |

### 6.2. Структура pillar/стандартной

1. **H1** — заголовок (см. §7).
2. **Лид** — 2–3 предложения. Что узнает читатель + почему ему это нужно.
3. **Карточка автора** — Екатерина или «Редакция» с фото и регалиями.
4. **Оглавление-якоря** — для статей длиннее 1500 слов.
5. **5–10 H2-блоков.** Каждый H2 — один логически законченный смысловой блок 200–400 слов.
   - H3 — внутри H2, при необходимости (1–3 H3 в одном H2). Не H4 и глубже.
6. **Пример из практики** — минимум 1. Для статей Екатерины — от 1-го лица. Для редакции — обезличенный.
7. **1–2 экспертные цитаты** или ссылки на исследования.
8. **3–5 иллюстраций** — hero + 2–4 в теле. Для МАК-статей — реальные карты из наших колод.
9. **FAQ-блок** — 5–8 пар вопрос-ответ в конце. Обязателен для статей-вопросов и лонгридов.
10. **Заключение** — 2–4 предложения. Не итоговый список, а связный текст-резюме.
11. **CTA** — **одна** кнопка/ссылка на коммерческую цель: `/cards`, `/mac`, `/ai`, `/artterapy`. Не три.
12. **Related** — «Читайте также» — 3–5 ссылок на статьи блога по теме.

### 6.3. Структура глоссарной

- H1 = термин (без оборотов «Что такое X»).
- Лид — 1–2 предложения, краткое определение.
- 2–4 H2 — детализация: происхождение термина, как используется, связанные понятия, примеры.
- Внутренние ссылки в плотную (5–10 на 600 слов).
- Без FAQ, без CTA (или 1 короткая ссылка на pillar-статью).

## 7. SEO-требования

### 7.1. Title

- **≤ 60–65 знаков** с учётом « — МакМагия» в конце (МакМагия подставится автоматически шаблоном — не дублируем в title).
- Содержит главный ключ в неискажённой форме в первой трети.
- Не дублирует H1 дословно — Title уточняет (год, цифру, выгоду).
- Без капса, без эмодзи.

Примеры:
- ✅ «Метафорические карты: что это и как работают»
- ✅ «МАК в работе психолога: техники для первой сессии»
- ❌ «Узнайте о МАК-картах прямо сейчас!»

### 7.2. Description

- **140–160 знаков.** Конкретная польза + призыв читать.
- Содержит главный ключ + 1 околотематический.
- Без точек в конце.

### 7.3. URL-slug

- Только латиница, kebab-case.
- 3–6 слов, без стоп-слов («и», «в», «для» — пропускаем).
- Содержит главный ключ в транслите.

Примеры:
- ✅ `/blog/chto-takoe-mak-karty`
- ✅ `/blog/mak-v-rabote-psihologa`
- ❌ `/blog/post-1`, `/blog/uznayte-pryamo-seychas-2026`

### 7.4. H1 / H2 / H3

- **H1** генерируется из `title`, в Body не пишем (или один на странице — зависит от движка блога).
- **H2** содержат подключи кластера. Пример для статьи «МАК что это»: H2 «Виды колод МАК», «Чем МАК отличается от Таро», «Как работают МАК в кабинете психолога».
- **H3** — детализация. Без ключевых слов в каждом H3 (это переоптимизация).

### 7.5. Плотность ключей

Главный ключ — **4–8 раз** в статье на 2000 слов. Распределён равномерно, не «в каждом абзаце». LSI/синонимы — органично.

Перетинг ключей запрещён.

### 7.6. Внутренняя перелинковка

- **3–5 внутренних ссылок** в теле статьи (на другие статьи блога / глоссарий).
- **1 коммерческая цель** в CTA + 1 раз органично в теле.
- На `provizorai.ru` — только в релевантных статьях про AI, **1 ссылка**, в теле (не футер).

### 7.7. Внешние ссылки

- **1–2 ссылки** на авторитетные источники (PubMed, APA, Cyberleninka, классические книги).
- `target="_blank" rel="noopener nofollow"` для всех внешних, **кроме** исследовательских (там без `nofollow` — сигнал авторитета).

## 8. Заголовки — правила

### Что да

- **Конкретная польза** в заголовке: «Метафорические карты: как использовать в работе с тревогой».
- **Вопросы** — да, если они реально из Wordstat-выдачи: «Как работают метафорические карты?», «Чем МАК отличается от Таро?».
- **Указание целевой аудитории**: «МАК для психолога», «МАК для родителей», «Арт-терапия для подростков».

### Что нет

- ❌ «N способов / N правил / N признаков / N техник» — AI-mill маркер, понижение в выдаче.
- ❌ Кликбейт: «Вы не поверите, что покажут карты», «Этот приём изменит вашу практику».
- ❌ Капс, восклицания, эмодзи, «!!!».
- ❌ Гарантии результата: «100% работает», «гарантированно поможет».
- ❌ Эзо-формат: «Карта дня», «Что говорят о вас МАК», «Расклад на 2026 год».

## 9. E-E-A-T требования

YMYL для нас — статьи про тревогу, депрессию, выгорание, отношения, детскую психологию, психотравму. Здесь требования жёстче.

### Обязательно для каждой YMYL-статьи

1. **Автор** — Каменская Екатерина (психолог) или «Редакция МакМагии» (с пометкой «материал проверен Е. Каменской, психологом»).
2. **Дата публикации + дата обновления** — обе видимы. При нетривиальном редактировании — обязательно бампать `updatedAt` (это попадает в `sitemap.xml` `lastmod`, через который поисковики понимают, что страница изменилась).
3. **Ссылка на источник** — минимум 1, на академический ресурс (APA, PubMed, Cyberleninka, классические книги).
4. **Дисклеймер для серьёзных тем** — депрессия, суицидальные мысли, психотравма: блок «Если вам тяжело сейчас» с телефонами помощи и фразой «статья не заменяет консультацию психолога».
5. **Не давать диагнозов в статье.** Только: «симптомы могут указывать на X — нужна консультация специалиста», не «у вас X, если N признаков».

### Что строго запрещено для YMYL

- ❌ Конкретные дозировки препаратов, схемы, названия лекарств с инструкциями.
- ❌ Гарантии излечения.
- ❌ Антинаучные методы: расстановки Хеллингера как «доказанный метод», регрессии, био-программы, НЛП «как факт работающей терапии».
- ❌ Советы про самолечение или самодиагностику с числовыми порогами («если у вас 5 из 7 симптомов, то у вас Х»).

## 10. Чек-лист перед публикацией

Прежде чем отдать статью — пройти весь список:

### Эзо-фильтр (§2)
- [ ] Ctrl+F по запретным словам — 0 совпадений.
- [ ] Если упоминается Таро — только в отстраивающем контексте со ссылкой на pillar.
- [ ] Никаких «карты говорят», «магически», «волшебно».

### Структура (§6)
- [ ] H1 + лид + (оглавление если >1500 слов) + 5–10 H2 + FAQ + CTA + related.
- [ ] Карточка автора (Екатерина или Редакция).
- [ ] Минимум 1 пример из практики.
- [ ] 3–5 иллюстраций с alt-текстом.

### Тон (§1, §5)
- [ ] Голос соответствует типу статьи (см. таблицу §1).
- [ ] Антимаркеры AI прогнаны (§5): «не X, а Y», «5+», «принципиально», канцелярские зачины, шаблонные финалы, триадные списки.
- [ ] Тон без снисхождения и без эзо-маркеров.

### SEO (§7)
- [ ] Title 60–65 знаков, ключ в первой трети, без бренда.
- [ ] Description 140–160 знаков, конкретная польза.
- [ ] URL-slug kebab-case, латиница, ключ в транслите.
- [ ] Плотность ключей 4–8 раз на 2000 слов.

### Внутренние ссылки (§7.6)
- [ ] 3–5 ссылок на другие статьи блога / глоссарий.
- [ ] 1 CTA на коммерческую страницу.
- [ ] Если про AI — 1 ссылка на provizorai.

### E-E-A-T (§9)
- [ ] Автор с регалиями.
- [ ] Дата публикации + дата обновления (если правка).
- [ ] 1–2 ссылки на источники (для YMYL — обязательно).
- [ ] Для серьёзных тем — дисклеймер с горячей линией.

### Заголовки (§8)
- [ ] Без «N способов…».
- [ ] Без кликбейта, без гарантий, без эзо-форматов.

### Точность (§4)
- [ ] Утверждения со статусом доказательности.
- [ ] Психо-техники в рамках школы-источника.
- [ ] Без диагнозов, без назначения препаратов.

### Финальный gut-check
- [ ] Перечитать статью вслух (или в голове) — звучит как живой человек или как LLM?
- [ ] Если как LLM — найти 3–5 «слишком гладких» предложений и переписать с конкретикой, личной деталью или паузой.

## 11. Эскалация — когда возвращаться с вопросом, а не публиковать

- Тема пересекается с эзо-кластером и непонятно, как обойти (например, «МАК и Юнг про синхроничность»).
- Не уверен в формулировке термина (можно ли назвать МАК «проективной методикой» в конкретном контексте).
- Не нашёл достоверного источника для YMYL-факта.
- Тема про суицид/РПП/тяжёлую травму — нужна вычитка профильным специалистом, а его нет.
- Нужно сослаться на конкретного российского психолога — нужно проверить, что он действительно специалист, не блогер-шарлатан.
- Тема пересекается со стоп-листом ([donors-shortlist.md §6](donors-shortlist.md)).

Лучше задать вопрос на этапе плана, чем переделать всю статью.

## 12. Поток работы в чате (для Claude в этом проекте)

Поскольку статьи пишутся **прямо в чате со мной** (Claude в проекте macmagia), а не через автономного агента — workflow такой:

### Шаг 1. Формат брифа от пользователя

Пользователь говорит:
> «Напиши статью по теме №1 из semantic-core-analysis.md: "Что такое МАК и как они работают"»

Или (более детально):
> «Тема: МАК для работы с нарциссическим клиентом. Ключ — `метафорические карты для психолога`, LSI: `техники мак карт`, `работа с НРЛ`. Длина 2500 слов. Автор — Екатерина.»

### Шаг 2. Я (Claude) перед написанием

1. Прочитать тему в [semantic-core-analysis.md](semantic-core-analysis.md) или [content-plan.md](content-plan.md).
2. Прочитать кластер ключей из [docs/seo/raw/wordstat-all-strict.csv](raw/wordstat-all-strict.csv) (фильтр по нужным фразам).
3. При необходимости — посмотреть ТОП-3 конкурентов в выдаче через WebFetch / WebSearch (если нужны актуальные тренды). Это **обязательно** для статей в нашей нише, чтобы понимать, как сейчас выглядят живые статьи в ТОП-10.
4. Перед написанием — спросить пользователя при сомнениях из §11.

### Шаг 3. Написание статьи

Пишу прямо в чат (как ответ) или в файл `docs/seo/articles/<slug>.md`. Договариваемся.

Если в файл — после написания возвращаюсь с резюме (количество слов, главные ключи, ссылки, замечания).

### Шаг 4. Внутренний чек-лист §10

Перед сдачей сам прохожу чек-лист. Сообщаю результат.

### Шаг 5. Ревизия пользователем

Пользователь читает, говорит правки или одобряет.

### Шаг 6. Публикация

Когда блог будет готов (он в плане — `lk.macmagia.ru/blog/` или `macmagia.ru/blog/`) — статья закоммичивается в репо.

Пока блога нет — статьи накапливаются в `docs/seo/articles/`.
