## Постановка задачи

Сейчас в `content-plan.md` 4 кластера и 10 первых тем. Этого хватит на 2 месяца блога. Чтобы покрыть рынок и догнать конкурентов (у b17 — 51K страниц, у psychologos — 16K), нужно **семантическое ядро на 500–1500 поисковых фраз**, сгруппированных в 100–250 статей.

Цель плана — собрать это ядро **системно**, отсортировать по приоритету и превратить в контентный календарь на 6–12 месяцев.

## Этап 1. Базовое ядро (2–3 дня, разовая работа)

**Результат этапа:** `docs/seo/semantic-core.csv` — таблица с ~500 поисковых фраз с реальными частотностями.

**Колонки CSV:**

| фраза | кластер | группа (=статья) | wordstat_total | wordstat_phrase | конкуренция (1–10) | приоритет (1–3) | целевой URL | дата добавления |
|---|---|---|---|---|---|---|---|---|

### Шаг 1.1. Затравочные фразы — 30 штук

По 5 фраз на каждый кластер из competitor-analysis §3:

**Кластер A (психо-тесты):**
- «тест на тип личности», «MBTI тест», «тест на привязанность», «тест на эмоции», «психологический тест онлайн».

**Кластер B (эмоции/состояния):**
- «как справиться с тревогой», «выгорание признаки», «панические атаки что делать», «прокрастинация причины», «эмоциональный интеллект».

**Кластер C (отношения):**
- «созависимые отношения», «токсичные отношения признаки», «типы привязанности», «как пережить расставание», «психологические границы».

**Кластер D (самопознание):**
- «как разобраться в себе», «упражнения для самопознания», «архетипы Юнга», «работа с травмой», «осознанность».

**Кластер E (родительство):**
- «детская тревога», «как воспитывать подростка», «истерики у ребёнка», «СДВГ у детей», «арт-терапия для детей».

**Кластер F (МАК/арт-терапия/AI — наша ниша):**
- «метафорические ассоциативные карты», «МАК в работе психолога», «арт-терапия техники», «AI для психолога», «нейросети в психотерапии».

### Шаг 1.2. Wordstat — реальные частоты

На каждой из 30 затравочных фраз Wordstat покажет:
- 50–200 связанных запросов с частотами;
- история динамики (растёт/падает тема).

**Как делать:**
- Открыть wordstat.yandex.ru, ввести фразу.
- Скопировать всё что нашлось (правая колонка «Похожие запросы» + левая «То что ищут с этим»).
- Сохранить в `docs/seo/raw/wordstat-<кластер>.txt` для каждого кластера.

**Альтернатива (если есть доступ к ключам API):** написать парсинг через Yandex Direct API → автоматически выгрузить за 1 запрос вместо ручного копирования. Это требует токена Direct.

### Шаг 1.3. Подсказки поисковика — длинные хвосты

**Скрипт:** для каждой затравочной фразы дёргаем Яндекс/Google suggest API без авторизации:
- Яндекс: `https://suggest.yandex.ru/suggest-ya.cgi?part=<query>` (JSON).
- Google: `https://suggestqueries.google.com/complete/search?client=firefox&q=<query>&hl=ru` (JSON).

**Что собираем:**
- Уровень 1 (Suggest от затравочной фразы) — 10 подсказок.
- Уровень 2 (Suggest от каждой подсказки уровня 1) — ещё по 10. Итого 100 подсказок на одну затравку, 3000 на 30 затравок.

**Как делать:** один Bash + jq скрипт. Сохраняем `docs/seo/raw/suggests-<кластер>.txt`. Я могу запустить локально на Mac за 5 минут.

### Шаг 1.4. Группировка по статьям

**Принцип:** одна группа = одна будущая статья. В группе 5–15 близких фраз.

**Алгоритм:**
1. Объединить все wordstat + suggest → один список из ~3500 фраз.
2. Удалить дубликаты, морфологические варианты схлопнуть (через pymorphy2 локально или вручную для критичных групп).
3. Кластеризация — TF-IDF + DBSCAN или ручная по корням ключевых слов. Для старта — ручная: отсортировать по алфавиту и пройти за час сверху вниз, помечая группы.
4. Каждая группа получает имя = главная фраза + slug.

### Шаг 1.5. Оценка конкуренции (1–10)

Для каждой группы открыть Яндекс по главной фразе и записать:
- **Сложность 1–3 (низкая):** в ТОП-10 — частные психо-блоги, узкоспециализированные сайты.
- **Сложность 4–6 (средняя):** в ТОП-10 — talentsy, psyh.info, psychologos, psy.systems.
- **Сложность 7–10 (высокая):** в ТОП-10 — b17, psychologies.ru, yasno + 3 страницы того же b17.

**Бонус-метка:** если в ТОП-3 есть эзо-сайт (таро, гадание, астрология) — пометить группу `EZO_RISK`. Эти группы — отдельный режим обработки (либо отказ, либо статья-отстройка от эзо).

### Шаг 1.6. Приоритизация (1–3)

Формула:
```
приоритет = (wordstat_phrase × probability_top10) / сложность
```

Где:
- `probability_top10` = 0.8 если у нас уже есть hub (МАК, арт-терапия, AI — там мы первопроходцы) и 0.3 для общих тем.
- `сложность` = 1–10 из шага 1.5.

Финальная разметка:
- **Приоритет 1:** первые 30 статей. Это hub-кластеры (МАК, арт-терапия, AI) + ВЧ-низкоконкурентные.
- **Приоритет 2:** статьи 30–80. ВЧ-среднеконкурентные.
- **Приоритет 3:** статьи 80–250. Длинные хвосты, глоссарий.

### Шаг 1.7. Запись в `semantic-core.csv`

Результат шагов 1.2–1.6 — итоговый CSV. Перед каждым большим этапом контента — пересмотр приоритетов.

## Этап 2. Длинные хвосты через комбинаторику (1 день, повторяемо)

**Что:** возьмём сильные шаблоны и развернём по матрице «тема × аудитория × запрос».

### Шаблоны

```
МАК для {аудитория: психолога | арт-терапевта | коуча | родителя | подростка | пары | группы | себя дома}
+ {задача: тревога | выгорание | отношения | самооценка | границы | травма | прокрастинация | расставание | целеполагание}

= 8 × 9 = 72 длинных хвоста для МАК-кластера
```

```
Арт-терапия для {аудитория: взрослых | детей | подростков | пожилых | травмы | депрессии}
+ {техника: рисование | глина | коллаж | мандала | сказка | метафорические карты}
= 36 длинных хвостов

```
{метод} + МАК
методы: КПТ | гештальт | психоанализ | схема-терапия | EMDR | системная семейная | арт-терапия | ACT | компассион
= 9 длинных хвостов
```

```
AI/нейросеть для {задача психолога: документация | подготовка к сессии | супервизия | подбор техник | диагностика | психообразование | обратная связь | этика | приватность}
= 9 длинных хвостов
```

**Результат:** ~125 длинных хвостов. У всех частота 50–500/мес, но конкуренция почти нулевая. Дрова для блога на 6 месяцев.

### Проверка комбинаторики

Не публиковать вслепую: каждый длинный хвост сначала проверяем в Wordstat — есть ли вообще хоть какие-то показы. Если 0 — отбрасываем (тема никому не нужна, никто так не ищет).

## Этап 3. Проверка через выдачу (континуально, перед каждой статьёй)

Для каждой группы фраз перед публикацией статьи:

1. **Открыть Яндекс** по главной фразе группы.
2. **Эзо-фильтр выдачи:** проверить, что в ТОП-10 — психология (не таро/гадания/астрология). Если в ТОП-3 эзо — отказ от группы или специальная статья-отстройка (см. писательский паттерн «МАК vs Таро» в content-plan.md #9).
3. **Изучить ТОП-3 статьи конкурентов:** длина, заголовки H2, тон, год публикации. Зафиксировать в комментарии к группе в CSV.
4. **Эталонная цель:** наша статья должна быть **на 30% глубже** хоть по одному параметру (более конкретный пример из практики, больше структурированных данных, лучшая фактология, видео-вставка).
5. **Записать целевой URL ТОП-1 конкурента** в CSV. Через 3 месяца после публикации — сравнить позиции.

## Этап 4. Контентный календарь (`content-calendar.md`)

Из `semantic-core.csv` выдвинуть в публикацию:
- **Первые 3 месяца:** 2 статьи в неделю = 24 статьи.
- **С 4-го месяца:** 3–4 статьи в неделю = 36–48 статей.

**Календарь:** таблица с колонками `дата | группа из core.csv | автор | статус (план/в работе/готова/опубликована/индексируется/в ТОП-10) | URL`.

**Распределение по кластерам в первые 3 месяца:**
- 8 статей кластер F (МАК + арт-терапия + AI) — наша ниша.
- 6 статей кластер A (психо-тесты) — главный трафик-драйвер.
- 4 статьи кластер B (эмоции).
- 3 статьи кластер D (самопознание).
- 2 статьи кластер C (отношения).
- 1 статья кластер E (родительство).

Этот баланс смещён в нашу нишу (F) — ставка на то, что мы выйдем в ТОП быстрее всех, потому что конкуренция там низкая (см. competitor-analysis §5–7).
