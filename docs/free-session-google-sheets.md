# Заявки со страницы /free-session/ → Google-таблица

Страница: `free-session/index.html` → https://macmagia.ru/free-session/
Код скрипта: [`free-session-apps-script.gs`](free-session-apps-script.gs)

Сервера у лендинга нет — это статика, отдаваемая nginx. Поэтому форма отправляет заявку
напрямую в веб-приложение Google Apps Script, а оно пишет строку в таблицу. Бесплатно,
без сторонних сервисов, доступ к заявкам — у владельца таблицы.

## Настройка (10 минут, делается один раз)

1. Создать таблицу: https://sheets.new — назвать, например, «Заявки на бесплатные сессии».
2. В таблице: **Расширения → Apps Script**.
3. В редакторе удалить всё содержимое `Code.gs` и вставить туда содержимое файла
   [`free-session-apps-script.gs`](free-session-apps-script.gs). Сохранить (дискета / Cmd+S).
4. **Развернуть → Новое развёртывание** (Deploy → New deployment).
5. Нажать шестерёнку рядом с «Выберите тип» → **Веб-приложение** (Web app).
6. Заполнить:
   - **Описание** — любое, например «приём заявок»;
   - **Запуск от имени** (Execute as) — **Я** (ваш аккаунт);
   - **У кого есть доступ** (Who has access) — **Все** (Anyone).
     Это обязательно: при «Только я» форма с сайта получит отказ.
7. **Развернуть** → Google попросит разрешения: «Разрешить доступ» → выбрать аккаунт →
   «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → «Разрешить».
   Это стандартный экран для своих же скриптов, не опубликованных в маркете.
8. Скопировать **URL веб-приложения** — длинный адрес вида
   `https://script.google.com/macros/s/AKfyc.../exec`.
9. Открыть `free-session/index.html`, найти внизу строку

   ```js
   var ENDPOINT = '';
   ```

   и вставить URL внутрь кавычек:

   ```js
   var ENDPOINT = 'https://script.google.com/macros/s/AKfyc.../exec';
   ```

10. Закоммитить и запушить в `main` — GitHub Actions выкатит страницу на сервер.

## Проверка

- Открыть URL веб-приложения прямо в браузере: должно ответить
  `{"ok":true,"service":"macmagia free-session","rows":0}`. Если просит войти в аккаунт —
  на шаге 6 стоит не «Все», а «Только я».
- Открыть https://macmagia.ru/free-session/, отправить тестовую заявку — строка появится
  в таблице через пару секунд, лист «Заявки» создастся сам.

## Метки рассылок по блокам курса

Сама страница всегда одна и та же — общий текст про практику студентов. Тему блока
(«прошли деньги — приходите с денежным запросом») вы задаёте в самом письме рассылки.

Чтобы потом было видно, какая рассылка сработала, добавляйте к ссылке метку:

| Блок | Ссылка для рассылки |
|---|---|
| Деньги и финансы | `https://macmagia.ru/free-session/?blok=dengi` |
| Отношения | `https://macmagia.ru/free-session/?blok=otnosheniya` |
| Самооценка и уверенность | `https://macmagia.ru/free-session/?blok=samoocenka` |
| Цели и выбор пути | `https://macmagia.ru/free-session/?blok=celi` |
| Состояние и ресурс | `https://macmagia.ru/free-session/?blok=resurs` |
| Родители и семья | `https://macmagia.ru/free-session/?blok=rod` |
| Без метки | `https://macmagia.ru/free-session/` |

Человек разницы не увидит — метка нигде не показывается, она просто уходит вместе
с заявкой в колонку **«Блок рассылки»**.

Метка может быть любой: `?blok=vebinar`, `?blok=vk-post` — что не найдётся в списке выше,
запишется в таблицу как есть. Список читаемых названий лежит в `free-session/index.html`
в переменной `BLOKI` — туда можно дописать свои.

Для поисковиков все эти адреса — одна страница: canonical ведёт на `/free-session/`,
а параметр `blok` добавлен в `Clean-param` в `robots.txt`, чтобы Яндекс не плодил дубли.

## Как этим пользоваться дальше

- Колонка **Статус** заполняется вручную: `Новая` ставится автоматически, дальше —
  `Взяли в работу`, `Проведена`, `Отказ`.
- Колонка **Блок рассылки** заполняется сама, если человек пришёл по ссылке с `?blok=`.
- Колонка **Кто взял** — имя студента, чтобы не звонили в одного человека вдвоём.
- Чтобы студенты видели заявки сами: **Настройки доступа** у таблицы → выдать доступ
  на редактирование по ссылке. Учтите — там персональные данные людей, так что лучше
  добавлять по конкретным адресам, а не «всем, у кого есть ссылка».
- Хотите уведомления вместо ручных проверок: в таблице **Инструменты → Правила
  уведомлений** → «Уведомлять о любых изменениях» → сразу письмом.

## Если что-то меняете в скрипте

После правки `Code.gs` изменения **не** попадают в работающий URL сами. Нужно:
**Развернуть → Управление развёртываниями** → карандаш → «Версия: Новая версия» →
**Развернуть**. URL при этом остаётся прежним, менять его в HTML не надо.

## Что защищает от спама

- Скрытое поле-ловушка `company`: браузер его не показывает, боты заполняют — такие
  заявки скрипт молча отбрасывает, в таблицу они не попадают.
- Заявка без имени или без единого контакта не сохраняется.
- Длина полей обрезается (запрос — 2000 символов), чтобы никто не залил в таблицу мусор.

Если спам всё же пойдёт — самое простое лечение — включить в форме капчу Яндекса
(SmartCaptcha) или переименовать ENDPOINT, развернув скрипт заново.

## Если заявки перестали приходить

1. Открыть URL веб-приложения в браузере — ответ `{"ok":true,...}` значит, что скрипт жив.
2. Apps Script → **Выполнения** (Executions) — видно каждый вызов и ошибки.
3. Проверить, что в `free-session/index.html` в `ENDPOINT` стоит актуальный URL:
   при **новом развёртывании** (а не при обновлении существующего) Google выдаёт **новый** адрес.
4. Квоты Apps Script: 20 000 вызовов в сутки для бесплатного аккаунта — упереться в них
   этой формой практически невозможно.
