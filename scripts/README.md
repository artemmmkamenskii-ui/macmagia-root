# scripts/

## build_blog.py — сборщик блога

Превращает markdown-статьи из `docs/seo/articles/*.md` в HTML под наш брендовый
шаблон, перегенерирует `blog/index.html` (хаб) и обновляет `sitemap.xml`.

### Установка зависимостей (один раз)

```bash
pip3 install -r scripts/requirements.txt
```

### Запуск

```bash
python3 scripts/build_blog.py
```

После прогона смотрим `git status` — должны измениться/появиться файлы в
`blog/` и `sitemap.xml`. Коммитим вместе с исходным markdown'ом.

### Что должен содержать markdown статьи

Frontmatter (YAML) — обязательные поля:

```yaml
---
slug: chto-takoe-mak-karty
title: "Метафорические карты (МАК): что это и как работают"
description: "Описание 140–160 знаков для meta description / OG"
publishedAt: 2026-06-04
updatedAt: 2026-06-09          # опционально
authorSlug: ekaterina-kamenskaya  # или macmagia-editorial
tags: ["метафорические карты", "МАК", "психология"]
category: "Метафорические карты"  # опционально, бейдж сверху статьи
emoji: 🃏                          # опционально, иконка карточки в хабе
coverGradient: 1                  # 1|2|3, цвет градиента карточки
ogImage: "https://macmagia.ru/about.jpg"  # опционально
readingTime: 15                   # опционально, иначе автосчёт
primaryKeyword: метафорические карты
lsiKeywords: [...]
targetCta: /cards
---
```

Custom markdown-блоки:

- **Pullquote** (декоративная цитата):
  ```
  ::: pullquote
  Короткая ёмкая мысль одним абзацем.
  :::
  ```

- **CTA-блок** (брендовая кнопка):
  ```
  ::: cta /cards "Колоды МакМагии"
  Текст вокруг кнопки, обычный markdown с **жирным** и [ссылками](/url).
  :::
  ```

- **Decorative divider** (тонкая разделительная линия с точкой):
  ```
  ---
  ```

- **H2-якоря** — старый синтаксис `## <a name="X"></a>Title` поддерживается;
  для нового можно ничего не указывать (анкор сгенерится из транслита заголовка).

- **Оглавление**: блок `## Оглавление` со списком удаляется при сборке
  (TOC автоматически рисуется из H2-заголовков).

- **FAQ-секция**: `## Частые вопросы…` или `## FAQ`. Каждый вопрос-ответ:
  ```
  **Вопрос с вопросительным знаком?**

  Текст ответа одним или несколькими абзацами.

  **Следующий вопрос?**

  Следующий ответ.
  ```
  Скрипт сам соберёт FAQ-карточки + `FAQPage` JSON-LD.

- **«Читайте также»**: трейлинг-блок `**Читайте также:**` в конце удаляется;
  related-ссылки автоматически выбираются по пересечению `tags` (топ-4).

### Эзо-фильтр

Скрипт падает с ошибкой, если в любом из markdown'ов нашлись запрещённые
слова из `docs/seo/agent-task.md §2` (магически, гадание, таро, чакры,
карма и т.п.). Это hard-gate против скатывания в эзо-cluster выдачи.

Чтобы обойти (только если уверен, что false-positive):
```bash
python3 scripts/build_blog.py --allow-eso
```
